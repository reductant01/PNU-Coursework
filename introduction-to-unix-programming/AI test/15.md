### 1-12
**문제:** `[ -f a -a -r a ]` 에서 **`-a`** 는 **AND**(둘 다 참). ( O / X )

**정답:** **O**

**해설:** `[ -f a -a -r a ]` 를 **조각**으로 보면:

| 부분 | 역할 |
|------|------|
| **`[` `]`** | `test` 명령 (조건 검사) |
| **`-f`** | **f**ile — **`a`가 일반 파일**이면 참 |
| **`a`** | 검사할 **파일 이름** (첫 번째) |
| **`-a`** | **a**nd — **앞·뒤 조건 둘 다** 참이어야 전체 참 |
| **`-r`** | **r**eadable — **`a`를 읽을 수 있으면** 참 |
| **`a`** | 같은 파일 **`a`** (두 번째 조건 대상) |

**의미 한 줄:** **`a`가 일반 파일이고`** **동시에** **`a`를 읽을 수 있으면** 참.


**복합 조건 (PDF slide 11):** **`-o`** = OR(하나만 참) · **`!`** = NOT(거짓 뒤집기).

### 1-13
**문제:** `[[ expression ]]` 은 `[ ]` 와 달리 **패턴 매칭**을 지원한다. ( O / X )

**정답:** **O**

**해설:**

**`[ ]` 란?**

- **`test` 명령**과 같음 · `if [ 조건 ]` = `if test 조건`
- **파일 검사:** `-f` `-d` `-r` … · **문자열/숫자:** `=` `!=` `\>` `-eq` …
- **글자 그대로** 비교 위주 (14.md Part1)

**`[[ ]]` 란?**

- bash **이중 대괄호** · 비슷한 조건 검사 + **추가 기능**
- PDF slide 12~13 — 특히 **패턴 매칭**

**패턴 매칭이란?**

- 문자열을 **완전히 같냐**만 보는 게 아니라, **와일드카드 패턴**에 **맞는지** 검사
- `*` = 아무 글자 여러 개 · `?` = 한 글자 · `[abc]` = a/b/c 중 하나

| | **`[ ]`** | **`[[ ]]`** |
|--|-----------|-------------|
| **정확히 같음** | `[ "$a" = "test" ]` | `[[ $a == test ]]` |
| **패턴 매칭** | **안 됨** (그대로 문자 비교) | `[[ $a == test* ]]` → `test`로 **시작**하면 참 |
| **파일 `-f` 등** | **주로 여기** (15.md) | 가능하지만 시험은 **`[ ]` 위주** |

**예 (개념):**

```bash
name=testing
[[ $name == test* ]]    # 참 — "test"로 시작
[ $name = test* ]       # test* 글자 그대로와 비교 → 거짓
```

**암기:** **`[ ]`** = 기본 `test` · **`[[ ]]`** = 패턴 매칭 등 **고급** (시험은 **차이만** 알면 됨).

### 1-14
**문제:** `case` 문은 **`esac`** 으로 끝난다 (`if`의 `fi`와 같음). ( O / X )

**정답:** **O**

**해설:** `if` ↔ `fi` 처럼 **`case` ↔ `esac`** (철자 거꾸로).

```bash
case $1 in              # ← case 시작
  start)
    echo "Starting..."
    ;;
  stop)
    echo "Stopping..."
    ;;
  *)
    echo "Usage: $0 {start|stop}"
    ;;
esac                    # ← case 끝 (fi 와 같은 역할)
```

| 키워드 | 역할 |
|--------|------|
| **`case … in`** | `$1` 값에 따라 **분기 시작** |
| **`esac`** | **`case` 블록 끝** |

---

### 1-15
**문제:** `case` 에서 패턴 끝에는 **`;;`** 가 필요하다. ( O / X )

**정답:** **O**

**해설:** 위 예시에서 **`;;`** = **이 분기 끝** · 다음 패턴 검사 **중단**.

```bash
case $1 in
  start)
    echo "Starting..."
    ;;                  # ← start 분기 끝
  stop)
    echo "Stopping..."
    ;;                  # ← stop 분기 끝
  *)
    echo "Usage..."
    ;;                  # ← default 분기 끝
esac
```

| 기호 | 역할 |
|------|------|
| **`;;`** | 이 패턴 처리 **종료** (`if`의 `fi` 한 블록 닫기와 비슷) |
| **`*)`** | **어떤 값이든** (default · else 와 비슷) |
| **`;;` 없음** | 아래 패턴으로 **넘어갈 수 있음** (fall-through) |

**실행 예:** `$1=start` → `Starting...` 만 출력 후 **`;;`** 로 `case` 종료.

### 3-4 (test14 · `-f` then `-r`)
**상황:** `/etc/shadow` 검사.

```bash
pwfile=/etc/shadow
if [ -f $pwfile ]
then
  if [ -r $pwfile ]
  then
    tail $pwfile
  else
    echo "Sorry, I'm unable to read the $pwfile file"
  fi
else
  echo "Sorry, the file doesn't exist"
fi
```

**문제:** 일반 사용자로 실행 시 **`-r` 실패** 시 출력 한 줄?

**정답:** **`Sorry, I'm unable to read the /etc/shadow file`**

**해설:** `-f` 통과(파일 존재) · `-r` 실패(읽기 권한 없음) → **else** · **`tail $pwfile`** 은 **실행 안 함**.

| 명령 | 역할 |
|------|------|
| **`tail`** | 파일 **끝부분**(마지막 줄들) **출력** · 여기선 읽기 가능할 때 비밀번호 파일 **일부** 보기용 |
| **이 문제** | `-r` 거짓 → `tail` **스킵** · 위 **Sorry…** 메시지만 출력 |

### 3-6 (`07.md` · `.bashrc`)
**상황:** 로그인 시 `.bashrc` 가 **파일**이면 불러옴.

```bash
if [ ______ ~/.bashrc ]; then
    ______ ~/.bashrc
fi
```

**정답:** **`-f`** / **`.`** (또는 **`source`**)

**해설:**

| 부분 | 역할 |
|------|------|
| **`-f`** | `~/.bashrc` 가 **일반 파일**로 **존재**할 때만 (1-3 · `-d`는 폴더) |
| **`.`** / **`source`** | 설정 파일 내용을 **지금 이 쉘**에서 **읽어 실행** |

**`.` = `./` 로 실행하는 것과 같나? → 아님**

|写法 | 의미 |
|------|------|
| **`. ~/.bashrc`** | **`source`와 동일** · **현재 쉘**에 `PATH`·`alias` 등 **바로 반영** |
| **`./myshell.sh`** | **자식 프로세스**에서 스크립트 실행 · 끝나면 **현재 쉘**에는 **안 남음** |
| **`.` (명령)** | “**현재 디렉터리**” `./` 가 **아님** · **`source`의 짧은 이름** |

**`source` 역할:** 파일 안 명령을 **복사해서 지금 쉘에서** 실행 → 로그인·`source ~/.bashrc` 후 **바로** `alias`·`PATH` 사용 가능 (`07.md` 1-12).
