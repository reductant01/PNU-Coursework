### 1-2
**문제:** 스크립트 **첫 줄** **`#!/bin/bash`** 는 **주석**이 아니라 **어떤 쉘로 실행할지** 알린다. ( O / X )

**정답:** **O**

**해설:** PDF slide 6.

**`#!/bin/bash` = shebang(쉬뱅) — 스크립트 **맨 첫 줄** 전용:**

```
#!/bin/bash
││ └─ /bin/bash  ← 이 **프로그램(쉘)** 으로 아래 줄들을 실행해라
│└── !  ← “이건 특별한 첫 줄이다” 표시
└─── #  ← 보통 주석이지만, **1행 + !** 이면 **주석 아님**
```

| 부분 | 뜻 |
|------|-----|
| **`#!`** | **sh**ebang — “**이 파일을 **어떤 인터프리터**로 실행할지**” 표시 |
| **`/bin/bash`** | **bash 쉘** 실행 파일 **경로** (Linux에서 흔한 위치) |

**왜 필요?** — 파일 **`test1`** 은 **텍스트**일 뿐 · OS는 **bash로 돌릴지 python으로 돌릴지** 모름 → **1행**이 **“bash로 읽어라”** 라고 알려 줌.

**2행부터 `#`:**

```bash
#!/bin/bash          ← shebang (실행)
# This is a comment  ← 진짜 주석 (쉘이 **무시**)
date                 ← 실제 명령
```

**실행:** **`chmod u+x test1`** 후 **`./test1`** — 커널/시스템이 **1행** 보고 **`/bin/bash test1`** 처럼 실행 (1-4).

**다른 예:** `#!/bin/sh` · Python은 `#!/usr/bin/python3` — **같은 shebang 패턴**.

### 1-5
**문제:** **`echo -n "text"`** 는 **줄바꿈 없이** 출력해 **다음 명령 출력과 같은 줄**에 이어 붙일 수 있다. ( O / X )

**정답:** **O**

**해설:** PDF slide 7.

**`echo` 기본:** 출력 **끝에 줄바꿈(Enter)** 이 **자동**으로 붙음 → **다음 출력은 무조건 다음 줄**.

**`echo -n`:** **줄바꿈 안 붙임** → **바로 이어서** 다음 출력 가능.

| 옵션 | 축약 | 뜻 |
|------|------|-----|
| **`-n`** | **n**o newline | 출력 **끝 줄바꿈(Enter) 생략** |

**PDF 예 (test1):**

```bash
echo -n "The time and date are: "
date
```

| | **`-n` 없음** | **`-n` 있음** |
|--|---------------|---------------|
| 화면 | `The time and date are:` ↵ ↵ `Mon Sep 24 …` ( **두 줄** ) | `The time and date are: Mon Sep 24 …` ( **한 줄** ) |

```
-n 없음:
The time and date are:
Mon Sep 24 20:11:35 EST 2007

-n 있음:
The time and date are: Mon Sep 24 20:11:35 EST 2007
```

**정리:** **`-n`** = **n**o newline — “**echo만** 출력하고 **Enter 치지 마**” → **`date`** 결과가 **같은 줄**에 붙음.

### 1-6
**문제:** **`echo "The cost is $15"`** 는 **`$1`** 과 **`5`** 로 해석되어 **`5`** 만 출력될 수 있다. ( O / X )

**정답:** **O**

**해설:** PDF slide 8.

**쉘 규칙:** **`"` 안에서도 `$`** 뒤는 **변수**로 해석됨 · **`$15`** = **`$1`** + **`5`** (15라는 변수 **아님**).

**왜 `$15`가 “15달러”가 아닌가?**

```
$15  →  $1  +  5
        │      └── 남는 글자 (숫자 5)
        └── **1번째 인자** 변수 ($1, $2, … $9 까지 이름 규칙)
```

| 표현 | 쉘이 읽는 뜻 |
|------|--------------|
| **`$1`** | 스크립트 **첫 번째 인자** |
| **`$15`** | **`$1`** 값 + 글자 **`5`** ( **`$15`라는 변수 없음** ) |
| **`${15}`** | (참고) **15번째 인자** — 시험은 **`$15` 함정** 위주 |

**이 문제 실행** (`./script` · **인자 없음** → **`$1` 비어 있음**):

```bash
echo "The cost is $15"
# $1 = (없음)  +  "5"  →  The cost is 5
```

**진짜 `$15` (달러 15) 출력:**

```bash
echo "The cost is \$15"
# → The cost is $15
```

**`\$`** = **`$` 기호 그대로** (변수 해석 **끔**) — 1-7.

**정리:** **`$` 뒤 숫자가 “안 읽히는” 게 아니라** — **`$1`까지 변수로 먼저 묶이고** **`5`만 남음**.

### 1-8
**문제:** **`value2=$value1`** → **`value2`에 숫자 10** · **`value2=value1`** → **문자열 `value1`**. ( O / X )

**정답:** **O**

**해설:** PDF slide 9 · **test4** — **변수에 값 넣기** 두 방식 비교.

**상황 (스크립트 test4):**

```bash
value1=10
```

이미 **`value1`** 이라는 변수에 **10**이 들어 있음.

---

**케이스 A — `$` 있음 (값 복사):**

```bash
value2=$value1
echo The resulting value is $value2
```

| 줄 | 의미 |
|----|------|
| **`value2=$value1`** | **`value1` 변수 안의 값(10)** 을 **`value2`에** 넣음 |
| **`echo … $value2`** | **`value2` 값** 출력 |

**출력:** `The resulting value is 10`

---

**케이스 B — `$` 없음 (글자 그대로):**

```bash
value2=value1
echo The resulting value is $value2
```

| 줄 | 의미 |
|----|------|
| **`value2=value1`** | **숫자 10이 아님** · **글자 `value1` 네 글자**를 문자열로 저장 |
| **`echo … $value2`** | 그 문자열 출력 |

**출력:** `The resulting value is value1`

---

**한 줄 규칙:**

| 쓴 코드 | **`value2`에 들어가는 것** |
|---------|---------------------------|
| **`value2=$value1`** | **`value1` 변수의 값** → **`10`** |
| **`value2=value1`** | **`$` 없음** → **이름 `value1` 글자 그대로** |

**`$` = “변수 **값** 꺼내기”** · **`=` 오른쪽에 `$` 빠지면** 변수 이름이 **텍스트**로 들어감.

### 1-10
**문제:** **백틱** **`` `date` ``** 는 **명령 실행 결과**를 변수·echo에 **넣는다**(command substitution). ( O / X )

**해설:** PDF slide 10 · test5.

**백틱(backtick)** = 키보드 **` **`** ( **`~` 옆** · **grave accent**)

**command substitution(명령 치환):** **`` `명령` ``** 안의 **명령을 먼저 실행** → **그 출력 문자열**이 **자리에 들어감**.

---

**PDF test5 — 날짜 문자열 넣기:**

```bash

```

| 단계 | 일어나는 일 |
|------|-------------|
| ① | **`date`** 실행 → 예: `Mon Sep 24 20:23:25 EDT 2007` |
| ② | 그 **한 줄 결과**가 **`testing` 변수**에 저장 |
| ③ | **`echo … $testing`** → 위 날짜 문자열 출력 |

**백틱 없으면 (`myshell2.sh`와 비교):**

```bash

```

**PDF slide 10 — 로그 파일 이름:**

```bash

# → log.070922 파일 생성
```

**`` `date +%y%m%d` ``** = **`date +%y%m%d` 실행 결과**만 **`today`에** · **`log.`** 와 **붙여서** 파일명.

## 부록 — Part 1 핵심 표

| 주제 | 암기 |
|------|------|
| **실행** | **`chmod u+x`** → **`./script`** |
| **shebang** | **`#!/bin/bash`** |
| **변수** | **`name=값`** ( **`=` 양쪽 공백 X** ) · **`$name`** |
| **문자열** | **`"..."`** 변수 치환 · **`'...'`** 그대로 |
| **명령 치환** | **`` `cmd` ``** 또는 **`$(cmd)`** |
| **리다이렉션** | **`>`** 덮어쓰기 · **`>>`** append · **`<`** 입력 · **`<<`** heredoc |
| **pipe** | **`cmd1 \| cmd2`** |
| **expr** | **공백 필수** · **`*`** → **`\*`** |
| **산술(bash)** | **`$(( ))`** — `myshell3.sh`, `average_two_numbers.sh` |

**Lecture 파일 역할:**

| 파일 | 연습 포인트 |
|------|-------------|
| **`myshell1.sh`** | `$USER`, `$HOME`, **`$(pwd)`**, **`$0`** |
| **`myshell2.sh`** | **`'date'`** vs **백틱** |
| **`myshell3.sh`** | **`$var1+$var2`** vs **`$(( ))`** |
| **`average_two_numbers.sh`** | **`read`**, **`$(( ))`** |
| **`history 10.sh`** | redirect, heredoc, **expr** |
