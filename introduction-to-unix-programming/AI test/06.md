## 유형 1. 개념 O/X

> **목표:** 틀리면 안 되는 **개념**부터 잡기. ( O / X )

---

### 1-1
**문제:** **Global environment variable**은 쉘 세션과 그 쉘이 만든 **자식 프로세스**에서도 보인다. ( O / X )

**정답:** **O**

**해설:** PDF slide 2~4. **전역(environment)** = `export`로 보낸 변수. 자식 `bash`·실행 프로그램에 전달됨.

---

### 1-2
**문제:** **Local variable**은 변수를 만든 **그 쉘 안**에서만 사용할 수 있다. ( O / X )

**정답:** **O**

**해설:** `test=값`만 한 경우 **현재 쉘**에만 존재. `export` 없이 `bash` 들어가면 자식에서 **안 보임**.

---

### 1-3
**문제:** `test = value`처럼 `=` **앞뒤에 공백**을 넣어도 변수 대입이 된다. ( O / X )

**정답:** **X**

**해설:** PDF slide 6. **`이름=값`**, `=` 앞뒤 **공백 없음**. 공백 있으면 `test`·`test2`를 **명령**으로 해석 → `command not found`.

---

### 1-4
**문제:** `export test`는 이미 있는 변수를 **환경 변수**로 보낸다. ( O / X )

**정답:** **O**

**해설:** `history 5.sh` 75행. `export` = 지역 변수를 **환경(전역)** 으로 승격.

---

### 1-5
**문제:** `env`는 **지역 변수만** 보여 준다. ( O / X )

**정답:** **X**

**해설:** `env` = **환경 변수(전역)** 목록 (`history 5.sh` 65행). 지역만 있는 변수는 `env`에 **안 나올 수** 있음.

---

### 1-6
**문제:** 부모에서 `export`한 변수는 자식 `bash`에서 볼 수 있다. ( O / X )

**정답:** **O**

**해설:** `export` 후 자식 쉘·프로세스에 **복사**되어 전달됨.

---

### 1-7
**문제:** `echo $PATH`는 `PATH` 변수 **값**을 출력한다. ( O / X )

**정답:** **O**

**해설:** `$PATH` = 변수 **값** 참조. `PATH`만 치면 **명령**으로 해석됨.

---

### 1-8
**문제:** `unset PATH` 후에도 모든 명령이 정상 동작한다. ( O / X )

**정답:** **X**

**해설:** `PATH` 없으면 `ls` 등 대부분 명령 **실행 불가** (`command not found`).

---

### 1-9
**문제:** `PWD`는 **현재 작업 디렉터리**를 나타낸다. ( O / X )

**정답:** **O**

**해설:** **P**resent **W**orking **D**irectory. `echo $PWD`로 확인.

---

### 1-10
**문제:** `export` 없이 만든 변수는 `env` 출력에 **항상** 나타난다. ( O / X )

**정답:** **X**

**해설:** `env`는 **환경 변수**만. 지역 변수만 있으면 목록에 **없음**.

---

### 1-11
**문제:** `PATH`는 쉘이 **입력한 명령**을 어느 **디렉터리**에서 찾을지 정하는 환경 변수이다. ( O / X )

**정답:** **O**

**해설:** PDF slide 9, 13~14. `:` 로 구분된 디렉터리 목록을 **순서대로** 검색.

---

### 1-12
**문제:** 자식 쉘에서 `unset test`하면 **부모 쉘**의 `test`도 함께 사라진다. ( O / X )

**정답:** **X**

**해설:** PDF slide 8. `unset`은 **그 쉘 안**에서만 삭제. 자식 `unset` = 자식 복사본만 제거, 부모 **영향 없음**.

---

### 1-13
**문제:** `PATH=~/mybin`은 기존 `PATH`를 **유지한 채** 경로를 **추가**한다. ( O / X )

**정답:** **X**

**해설:** `PATH=~/mybin` = **교체**(위험). **추가** = `PATH=$PATH:~/mybin`. `history 2.sh` 17~18행.

---

### 2-10

**해설:** `history 5.sh` 73행. `exit` 명령과 동일.

### 2-11

## 유형 3. 명령줄·설정 빈칸 (여러 줄)

> **소스·설정 조각** 빈칸 (공지: source codes)

---

### 3-1
**상황:** PDF 변수 대입 예시 — **올바른** 줄만 고르고, 공백 값에 필요한 것을 쓰시오.

```bash
test=testing a long string    # (가)
test='testing a long string'  # (나)
test2 = test                  # (다)
```

**문제:** (가)(나)(다) 중 **올바른 대입**은? 공백 값에 필요한 것은?

**정답:** **(나)만 올바름** · 공백 있는 값 → **작은따옴표 `'`** 또는 큰따옴표 `"`로 **한 덩어리**로 감싸기

**해설:** (가) `a`가 **새 명령** → `-bash: a: command not found`. (다) `test2` **명령**으로 해석. `test2=test`는 공백 없으면 **정상**.

---

### 3-2
**상황:** 변수 만들고 → export → 자식 쉘에서 확인.

```bash
myvar=hello
______ myvar
______
echo $myvar
```

**정답:** `export` / `bash`

**해설:** **만들기 → export → bash**. `export` 전에 `bash` 들어가면 자식에서 **안 보임**.

---

### 3-3
**상황:** 변수 설정 → 확인 → 삭제.

```bash
test=testing
echo $test
______ test
echo $test
```

**정답:** `unset`

**해설:** PDF slide 8. 마지막 `echo $test` → **(빈 줄)**.

---

### 3-4
**상황:** `~/.bashrc`에 `PATH` 수정 후 **현재 쉘에 바로 반영** (`history 2.sh`).

```bash
# ~/.bashrc 에 PATH=$PATH:~/mybin 추가 후
______ ~/.bashrc
```

**정답:** `source` (또는 `.`)

**해설:** `history 2.sh` 19행. 설정 파일을 **현재 쉘에서 다시 읽기**.

---

### 3-5
**상황:** `history 2.sh` — PATH 확인·추가.

```bash
echo $______
PATH=$______:~/mybin
```

**정답:** `PATH` / `PATH`

**해설:** `echo $PATH` = 현재 값 확인 · `PATH=$PATH:경로` = **append** 패턴.

---

### 3-6
**상황:** `history 5.sh` — 값 이어 붙이기.

```bash
test='testing a b c'
test=$test:______
```

**정답:** `.` → `test=$test:.`

**해설:** `history 5.sh` 79행. `$test` = 기존 값, 뒤에 `:.` **연결**.

## 유형 4. 순서·로직 빈칸

> **알고리즘·워크플로 순서** (공지: coding algorithms)

---

### 4-1
**문제:** 변수 `myvar`를 만들고, 자식 쉘에서도 쓰게 한 뒤, 나중에 제거한다. **번호** (1~4).

```
( ) unset myvar
( ) myvar=hello
( ) export myvar
( ) bash   # 자식에서 echo $myvar 확인
```

**정답:** 1. `myvar=hello` · 2. `export myvar` · 3. `bash` · 4. `unset myvar`

**해설:** **만들기 → export → 사용(자식) → unset**. `export` 전에 자식 들어가면 값 **안 보임**.

---

### 4-2
**문제:** 지역 변수를 **자식 쉘에서 보이게** 하는 **3단계** 순서.

**정답:** ① `test=값` (대입) → ② `export test` → ③ `bash` (또는 자식 프로세스 실행)

---

### 4-3
**문제:** `PATH`에 새 디렉터리를 **안전하게 추가**하는 단계 (덮어쓰지 않음).

**정답:** ① `echo $PATH` (현재 확인) → ② `PATH=$PATH:새경로` → ③ `echo $PATH` (반영 확인)

**해설:** `PATH=새경로`만 쓰면 **교체** — 기존 `/usr/bin` 등 **사라짐**.

---

### 4-4
**문제:** `env | sort | more` 파이프 **3단계** 역할 순서.

**정답:** ① `env` — 환경 변수 목록 출력 → ② `sort` — 정렬 → ③ `more` — 한 화면씩 보기

**해설:** `history 2.sh`. `|` = 이전 명령 **표준출력**을 다음 명령 **입력**으로.

## 유형 5. 상태·메시지 예측

> **오류 메시지·`env` 출력 형식** (공지: command outcomes)

---

### 5-1
**상황:** 터미널에 아래를 **그대로** 입력.

```bash
test=testing a long string
test2 = test
```

**문제:** (1)(2) 각각 나는 메시지 유형은?

**정답:** (1) `-bash: a: command not found` (2) `-bash: test2: command not found`

**해설:** (1) 공백 뒤 `a`가 **별도 명령** · (2) `=` 앞뒤 공백 → **대입 아님**.

---

### 5-2
**상황:** `env | grep USER` 실행.

**문제:** 한 줄 출력 **형태**는?

**정답:** `USER=사용자이름` (예: `USER=sj`)

**해설:** `env` = `이름=값` 형식. `grep USER` = USER 포함 줄.

---

### 5-3
**상황:** 홈 디렉터리 경로 확인.

**문제:** (1) `echo $HOME` (2) `HOME`만 입력 — (2)에서 쉘이 하는 일은?

**정답:** (1) 홈 **경로 출력** (2) `HOME`이라는 **명령**을 찾으려 함 → **command not found**

**해설:** 값을 쓸 때 **`$` 필수**. `$test` = **값** · `test`만 = **명령 이름**.

---

### 5-4
**상황:** `myprog` 실행 파일이 `/home/user/test/myprog`에만 있고, `PATH`에 그 경로가 **없다**.

**문제:** 쉘에서 `myprog`만 입력하면 나는 메시지는?

**정답:** `-bash: myprog: command not found` (또는 **command not found**)

**해설:** PDF slide 13. `PATH`에 없으면 실행 파일 **못 찾음**.

---

### 5-5
**상황:** 원래 `PATH`에 `/usr/bin` 등이 있었음.

**문제:** `PATH=/tmp` 실행 후 `ls` 입력 시?

**정답:** `-bash: ls: command not found` (또는 **command not found**)

**해설:** `PATH=/tmp` = **교체**(위험). `PATH=$PATH:경로`가 **추가** — 시험 포인트.

---

### 5-6
**상황:** `export` 없이 `env` 실행.

**문제:** 방금 `test=hello`만 한 **지역 변수** `test`는 `env` 출력에 나타나는가? 한 줄 이유는?

**정답:** **나타나지 않음** · `env`는 **환경 변수(전역)** 만 출력

**해설:** 지역만 있으면 `echo $test`로는 보이지만 `env` 목록에는 **없음**.

## 유형 6. 실행 결과 예측

> **부모/자식 쉘·`export`·`unset` 실행 결과** (공지: outcomes)

---

### 6-1
**상황:** `export` **없이** 지역 변수 + 자식 쉘.

```bash
test='testing a long string'
bash
echo $test    # (1)
exit
echo $test    # (2)
```

**문제:** (1)(2) 출력? (1)에서 아무것도 안 나오면 **빈 줄**.

**정답:**  
(1) **(빈 줄 — 출력 없음)**  
(2) `testing a long string`

**해설:** PDF slide 6~7. **지역 변수**는 자식 (1)에 **전달 안 됨**. `exit` 후 부모 (2)에서 다시 보임.

---

### 6-2
**상황:** 6-1과 같지만 첫 줄이 `test=hello` (따옴표 없음).

```bash
test=hello
bash
echo $test
```

**문제:** `export` 없이. 자식 쉘 출력은?

**정답:** **(빈 줄 — 아무것도 출력 안 됨)**

**해설:** 6-1과 동일 — **지역**은 자식에 **안 넘어감**.

### 6-3
**상황:** `export` 후 자식 쉘.

```bash
test=hello
export test
bash
echo $test
```

**문제:** 출력은?

**정답:** `hello`

**해설:** `export` → **환경 변수** → 자식에서 `$test` 사용 가능.

---

### 6-4
**상황:** `unset` 기본.

```bash
test=testing
echo $test
unset test
echo $test
```

**문제:** 마지막 `echo $test` 출력은?

**정답:** **(빈 줄)**

**해설:** PDF slide 8. `unset` = 변수 **완전 제거**.

---

### 6-5
**상황:** `export` + 자식 `unset` — **핵심** (PDF slide 8).

```bash
test=testing
export test
bash
echo $test    # (1)
unset test
echo $test    # (2)
exit
echo $test    # (3)
```

**문제:** (1)(2)(3) 출력? (1)이 **X**인 이유(1-12)를 **한 줄**로?

**정답:**  
(1) `testing`  
(2) **(빈 줄)**  
(3) `testing`  
· `unset`은 **그 쉘 안**에서만 삭제 — 자식 `unset`이 부모 **환경 변수**에 영향 없음

**해설:** `export`로 부모가 자식에 **복사본** 전달. 자식 `unset` (2) = 자식만 삭제. 부모 (3) **그대로** `testing`.

### 6-6
**상황:** 값 이어 붙이기 (`history 5.sh`).

```bash
test='testing a b c'
test=$test:.
echo $test
```

**문제:** 출력은?

**정답:** `testing a b c:.`

**해설:** `$test` = 기존 값, `:.` **문자열 연결**.

### 6-7
**상황:** `PATH` 추가 전·후 (`history 2.sh` + PDF).

```bash
myprog    # ~/mybin/myprog 만 존재, PATH에 ~/mybin 없음
PATH=$PATH:~/mybin
myprog
```

**문제:** (1) `PATH` 추가 **전** `myprog` (2) 추가 **후** `myprog` — 각각?

**정답:** (1) **command not found** (2) **`myprog` 실행됨**

**해설:** `PATH=$PATH:경로` 후 해당 디렉터리 실행 파일을 **이름만으로** 실행 가능.

### 6-8 (종합)
**상황:** 아래를 **순서대로** 실행.

```bash
test=local
export test
bash
test=child_only
echo $test
exit
echo $test
unset test
echo $test
```

**문제:**  
(1) 자식에서 `echo $test`  
(2) `exit` 후 부모에서 `echo $test`  
(3) `unset test` 후 `echo $test`  
(4) `test=child_only`는 어느 쉘에만 남는 **지역** 변수?

**정답:**  
(1) `child_only` (자식 **재대입** — export 값 덮어씀)  
(2) `local` (부모 **변경 없음**)  
(3) **(빈 줄)**  
(4) **자식 쉘** 안에서만

**해설:** 자식 재정의는 부모에 **안 남음**. 부모 `unset`은 부모에서만 삭제. PDF slide 6~8 + `history 5.sh` 종합.
