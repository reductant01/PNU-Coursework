## 유형 1. 개념 O/X

### 1-1
**문제:** `var1=$[1 + 5]` 처럼 **`$[ ... ]`** 로 계산하면 기본적으로 **정수(integer)** 연산만 된다. ( O / X )

**정답:** **O**

**해설:** PDF slide 2~3 · test7·test8.

**`$[ ]` = 정수 산술** — **명령 실행 아님** · **소수점 X** (1-2).

**`$()` · `$[ ]` · `$(( ))` — 헷갈리기 쉬움:**

| 표기 | 하는 일 | 예 |
|------|---------|-----|
| **`$(cmd)`** | **명령 치환** — `cmd` **실행** → 출력 문자열 | `$(date)` → 날짜 문자열 (11.md) |
| **`$[ expr ]`** | **정수 산술** (PDF 12) | `$[1+5]` → **6** |
| **`$(( expr ))`** | **정수 산술** (현대식 · Lecture) | `$((1+5))` → **6** |

→ **`$()`** 와 **`$[ ]`** 는 **완전히 다름** · **`$[ ]`** ≈ **`$(( ))`** (둘 다 **숫자 계산**, 정수만).

```bash
var1=$[1 + 5]              # → 6        (산술)
today=$(date +%y%m%d)      # → 260608…  (명령 결과)
var3=$((var1 + var2))      # → 30       (산술 — myshell3.sh)
```

**소수 필요** → **`bc`** (1-3) · `$[ ]` / `$(( ))` 로는 **2.2222** 같은 값 **불가**.

### 1-3
**문제:** 부동소수점 계산은 보통 **`bc`** 로 해결한다. ( O / X )

**정답:** **O**

**해설:** PDF slide 4~9 · `average_with_loops.sh`.

---

**① `bc`는 변수가 아님 — **명령(프로그램)****

| | **`bc`** | **`var1`** (변수) |
|--|----------|-------------------|
| **뭐냐** | **계산기 프로그램** (`date`, `ls`처럼 **명령**) | 스크립트 안 **이름 붙인 상자** |
| **실행** | 터미널에 **`bc`** 치면 계산기 켜짐 | **`var1=10`** 처럼 **값 저장** |

**`bc`** = **b**asic **c**alculator — **소수점 계산**용 **외부 프로그램**.

---

**② 백틱 `` ` ... ` `` 역할 (11.md 복습)**

```bash
var1=`echo "scale=4; 3.44 / 5" | bc`
     └────────── 이 안 전체가 한 번 실행 ──────────┘
     └── 실행 **결과 문자열**이 var1에 들어감 → .6880
```

| | |
|--|--|
| **백틱** | **명령 치환** — `` `명령` `` **실행** → **출력**을 그 자리에 꽂음 |
| **`$(명령)`** | **같은 뜻** (요즘 더 많이 씀) |

→ **`bc`가 변수가 아니라**, 백틱 **안에서 `bc` 명령을 돌린 결과**를 **`var1` 변수**에 넣는 것.

---

**③ 한 줄씩 쪼개 보기**

```bash
var1=`echo "scale=4; 3.44 / 5" | bc`
```

| 순서 | 누가 | 하는 일 |
|------|------|---------|
| 1 | **`echo "scale=4; 3.44 / 5"`** | 그 **문자열**을 stdout으로 출력 |
| 2 | **`|`** | 그 출력을 **`bc` 프로그램** 입력으로 넘김 |
| 3 | **`bc`** | 받은 문자열을 **계산** → 결과 **`.6880`** 출력 |
| 4 | **백틱** | 그 출력 **`.6880`** 을 **`var1`** 에 저장 |

---

**④ `scale=4;` — shell 명령이 아니라 **bc 안의 설정**

**따옴표 `"..."` 안**은 **bc에게 보내는 글자**입니다. **쉘이 `scale` 명령을 실행하는 게 아님.**

```
"scale=4; 3.44 / 5"
  │       │
  │       └─ bc에게: "이 식 계산해" (3.44/5)    
  └─ bc에게: "소수 4자리까지 보여줘" (bc **내부 변수** scale)
```

| | **shell의 `;`** (1-1) | **bc 안의 `;`** (이 문제) |
|--|----------------------|---------------------------|
| **위치** | 터미널·스크립트 | **`echo "…"` 문자열 안** |
| **역할** | **명령과 명령** 연결 (`date; who`) | **bc 문장과 bc 문장** 연결 |
| **누가 이해** | **bash** | **`bc` 프로그램** |

**`scale`** = **bc 전용 설정 이름** (bash 변수 **아님**) · 기본값 **0** (1-4).

---

**⑤ 왜 `bc`를 쓰나?**

```bash
$[100 / 45]              # → 2        (정수만 — 1-2)
echo "scale=4; 100/45" | bc   # → 2.2222  (소수)
```

**1-3 정답 O** — 부동소수점은 **`$[ ]`로 안 되고** → **`bc` 명령**으로 해결.

### 1-6
**문제:** 스크립트에서 마지막으로 실행한 명령의 exit status는 **`$?`** 에 들어 있다. ( O / X )

**정답:** **O**

**해설:** PDF slide 10~11.

**exit status(종료 코드) = 명령·프로그램이 끝날 때 OS에 돌려주는 작은 정수**

```
명령 실행 → (일 처리) → 끝 → "나는 N으로 끝났어" (exit status)
                              ↑
                         echo $? 로 확인
```

| 용어 | 뜻 |
|------|-----|
| **exit status** | = **exit code** = **종료 코드** (같은 말) |
| **`$?`** | **바로 직전 명령**이 돌려준 그 **숫자**를 담는 **특수 변수** |

**명령마다 숫자가 다른 이유:** 각 명령·오류 종류마다 **정해진 규칙**이 있음 (전부 같지 **않음**). 시험·PDF는 **대표 예**만 외우면 됨.

| 상황 (PDF) | 직후 `$?` | 의미 |
|------------|-----------|------|
| **`date`** 등 **정상 실행** | **0** | **성공** (거의 모든 명령 공통) |
| **`asdfg`** — 없는 명령 | **127** | **command not found** (5-1) |
| **`./myprog.c`** — 실행 권한 없음 | **126** | **Permission denied** (5-2) |
| **`date %t`** — 잘못된 옵션 | **1** | **일반 오류** (5-3) |
| 스크립트 **`exit 5`** | **5** | **직접 지정** (2-6) |
| 스크립트 **`exit 300`** | **44** | **255 초과** → modulo로 **축소** (1-9, 5-5) |

**흐름 예:**

```bash
date
echo $?          # → 0     ← date는 성공

asdfg            # 에러 메시지 출력
echo $?          # → 127   ← asdfg의 종료 코드 (date 아님!)
```

**헷갈림 정리:**

| 질문 | 답 |
|------|-----|
| **종료 코드가 뭐냐?** | 명령이 **끝날 때** 남기는 **성공/실패 번호** |
| **`$?`는 뭐냐?** | 그 번호를 **읽는 변수** (직전 명령 것만) |
| **왜 명령마다 다르냐?** | **성공=0**은 공통 · **실패 번호**는 **오류 종류**마다 다름 |
| **언제 바뀌냐?** | **새 명령** 실행할 때마다 **갱신** (1-7) |

**스크립트:** `exit` 안 쓰면 **마지막 명령**의 exit status가 스크립트 전체 코드 (1-10).

### 1-8
**문제:** `exit` 로 나가는 exit code는 기본적으로 **0~255 범위**로 제한된다. ( O / X )

**정답:** **O**

**해설:** PDF: “exit status codes can only go up to 255”.

---

### 1-9
**문제:** `exit 300` 같은 값은 300 그대로 유지되고, 0~255 제한과 무관하다. ( O / X )

**정답:** **X**

**해설:** PDF slide 12~13 · test14b.

**exit status는 0~255만** 사용 가능 (1-8). **256 이상**이면 **modulo(나머지)** 로 줄어듦.

```
exit 300
     ↓
300 ÷ 256 = 1 … **나머지 44**
     ↓
실제 exit status = **44**
```

| | |
|--|--|
| **스크립트** | `exit 300` |
| **기대(틀림)** | `$?` = **300** |
| **실제 (PDF)** | `$?` = **44** |

**확인:**

```bash
# test14b 형태
exit 300
echo $?          # → 44  (5-5)
```

**공식:** **지정값 mod 256** · 300 mod 256 = **44**

**이 문제 X** — 300 **그대로 유지 안 됨** → **44**로 축소.
