### 1-9
**문제:** vim **복사(copy)** 명령은 **`y`** (**y**ank). ( O / X )

**정답:** **O**

**해설:** PDF slide 10 · `history 2.sh`.

**yank 뜻:**

| | |
|--|--|
| **yank** | 영어 **“잡아당기다·끌어오다”** → vim에서는 **복사(copy)** |
| **`y`** | **y**ank — 선택·줄·단어를 **register에 복사** |
| **`yy`** | **한 줄** yank (= **`Y`**) |

**register(레지스터) — `dd`와 `y` 공통:**

| 명령 | register에 |
|------|------------|
| **`dd`** (삭제/cut) | 지운 내용 **저장** → **`p`** 로 붙여넣기 |
| **`yy`/`yw`** (yank) | 복사 내용 **저장** → **`p`** 로 붙여넣기 |

**“삭제 후 복사하면 삭제분 복구?” — 시험·PDF 수준 정리:**

- **기본(unnamed) register** 는 **마지막 `dd` 또는 `y` 중 하나**만 들고 있음 → **`yy` 다음 `p`** 는 **복사본** · **`dd` 직후 `p`** 는 **삭제한 줄**.
- **`dd` → `yy` 순서**면 register가 **복사 내용으로 덮어씀** → **`p`로는 삭제분 못 살림**.
- **삭제 취소**는 **`p`가 아니라 **`u`** (undo) — `dd` **직후 `u`** = 삭제 **되돌리기** (`history 2.sh`).

### 1-12
**문제:** 검색: **`/`** + 문자열 + **Enter** · 같은 단어 **다음**: **`n`**. ( O / X )

**정답:** **O**

**해설:** PDF slide 12 · `history 2.sh`.

**검색 — 순서대로 (Normal mode):**

```
/          ← 검색 시작 (forward = 앞으로 찾기)
error      ← 찾을 문자열 입력
Enter      ← 검색 실행 → 첫 번째 "error"로 커서 이동
n          ← 같은 문자열 **다음** occurrence
N          ← **반대 방향** (보통 **이전** occurrence)
```

**`/` · `n` · `N` 뜻:**

| 입력 | 축약·의미 |
|------|-----------|
| **`/`** | **검색 명령** (앞으로 찾기) — `?` = **뒤로** 찾기 |
| **`n`** | **n**ext — **다음** 검색 결과 (마지막 `/`·`?` 와 **같은 방향**) |
| **`N`** | **N**ext (대문자) — **반대 방향** · `/` 로 찾았으면 **이전** · `?` 로 찾았으면 **다음** |

**예:** 파일에 `error`가 3번 있음 · `/error` Enter → **1번째** · **`n`** → 2번째 · **`n`** → 3번째 · **`N`** → 2번째.

**`history 2.sh`:** 커서 아래 단어와 **완전히 같은 단어** 찾기 = **`*`** · 이후 **`n`** / **`N`** 동일.

### 1-13
**문제:** **`:%s/old/new/g`** 는 **파일 전체**에서 `old`→`new` **전부** 치환한다. ( O / X )

**정답:** **O**

**해설:** PDF slide 13 · `history 2.sh`: `:%s/is/was/gc`.

**`: %s / old / new / g` — 조각마다 역할:**

```
:     %     s    /old/new/   g
│     │     │         │      │
│     │     │         │      └─ g = global (그 줄 안 **전부**)
│     │     │         └─ old→new (바꿀 내용)
│     │     └─ s = **s**ubstitute (치환 명령)
│     └─ % = **전체 줄** (all lines)
└─ Command mode (Normal에서 `:`)
```

| 부분 | 축약 | 역할 |
|------|------|------|
| **`:`** | — | **Command line mode** |
| **`%`** | all lines | **파일 전체** 줄 범위 (1행~끝) |
| **`s`** | **s**ubstitute | **치환** 명령 자체 |
| **`/old/new/`** | — | **old** 찾아 **new** 로 바꿈 (구분 `/` 는 **구분자**) |
| **`g`** | **g**lobal | **한 줄 안**에서 **첫 번째만**이 아니라 **나오는 전부** |

**`g` 없으면 vs 있으면 (같은 줄 `aa aa`):**

| 명령 | 결과 |
|------|------|
| **`: %s/aa/bb/`** (`g` 없음) | **`bb aa`** — 줄마다 **첫 `aa`만** |
| **`: %s/aa/bb/g`** | **`bb bb`** — 줄마다 **전부** |

**`%` 없으면:** **`:s/old/new/g`** = **현재 줄만** (PDF slide 13).

**`c` 붙이면:** **`: %s/old/new/gc`** — **g**lobal + **c**onfirm(매번 y/n) · `history 2.sh`.

### 1-15
**문제:** 수정 **없이** 종료: **`:q`** · 수정 **버리고** 종료: **`:q!`**. ( O / X )

**정답:** **O**

**해설:** PDF slide 6 · `history 2.sh`.

**세 가지 종료 — 차이:**

| 명령 | 축약 | 언제 | 저장? |
|------|------|------|-------|
| **`:q`** | **q**uit | **수정 없음** → 바로 종료 · **수정 있음** → **경고** (그냥 안 나감) | **안 함** |
| **`:q!`** | quit **!**(force) | **수정 있어도** **저장 안 하고** 강제 종료 | **버림** |
| **`:wq`** / **`:x`** | **w**rite + **q**uit | **수정 반영해서** 저장 **후** 종료 | **함** ← **수정하고 끝낼 때** |

**`!` 뜻:** shell처럼 **“강제·확인 무시”** — **`:q!`** = “저장 말고 **그냥 나가**”.

**흐름 예:**

```
편집 안 함     →  :q          OK
편집했는데 저장  →  :wq  (또는 :x)   OK
편집했는데 버림  →  :q!         OK (변경 사라짐)
편집만 하고 :q  →  경고 — "No write since last change" 등
```

**저장만 하고 계속 편집:** **`:w`** (`history 2.sh`).

**Insert mode 들어가는 키 — `i`와 짝:**

| 키 | 뜻 | 하는 일 |
|----|-----|---------|
| **`i`** | **i**nsert | **커서 위치**에서 입력 시작 |
| **`I`** | **I**nsert | **줄 맨 앞**(첫 글자)으로 이동 후 입력 |

| **`i`** | `hello` **여기서** 입력 |
| **`a`** | `hello**|**` ← `o` **뒤**에서 입력 |
| **`A`** | `hello` **끝**에서 입력 |
| **`o`** | `hello` **다음 줄** 새로 만들어 입력 |

**공통:** 입력 끝나면 **`Esc`** → Normal.

### 2-11
**상황:** **한 단어** yank (PDF slide 10).

**정답:** **`yw`**

**해설:** PDF slide 10.

**정답 `yw` = 키 두 개를 **연달아**:**

```
y  +  w
│     └── w = **다음 단어까지** 범위
└── y = **y**ank (복사)
```

**예 — 한 줄 `hello world` · 커서가 `h`:**

| 입력 | 파일 내용 변화 | register | 커서 |
|------|----------------|----------|------|
| **`w`만** | **그대로** `hello world` | 변화 없음 | **`world`의 `w`** 로 **이동만** |
| **`yw`** | **그대로** (화면은 안 바뀜) | **`hello` 저장** | **`world`의 `w`** 근처 |
| **`p`** | `hello hello world` 등 **붙여넣기** | — | — |

→ **`w`만** = **커서 이동** (복사 X) · **`yw`** = **이동 범위만큼 복사** (텍스트는 **`p` 전까지** 그대로).

**`w` = word (이동 키):** 다음 **단어 첫 글자**로 건너뜀 · **`b`**=이전 단어 · **`e`**=단어 끝.

**같은 `[동작][이동]` 패턴:**

| 명령 | 의미 |
|------|------|
| **`yw`** | **한 단어** 복사 ← **이 문제** |
| **`y$`** | **줄 끝까지** 복사 |
| **`yy`** | **한 줄** 복사 |
| **`dw`** | **한 단어** 잘라내기 (`d` + `w`) |

|---------|------|
| `u` | ______ |

**정답:** **undo(실행 취소)** / **마지막 줄로 이동** / **검색 다음 occurrence** / **저장(write)**

**해설:** `history 2.sh` — 각각 축약:

| 키·명령 | 축약 | 역할 |
|---------|------|------|
| **`u`** | **u**ndo | **직전 편집** 한 번 **취소** (`dd`·`i` 입력 등) |
| **`G`** | **G**o (to line) | **파일 마지막 줄**로 이동 · **`5G`** = 5행 · **`gg`** = 첫 줄 |
| **`n`** | **n**ext | **`/`·`?` 검색** 후 **다음** 결과 (1-12) · **`N`** = 반대 방향 |
| **`:w`** | **w**rite | **저장** (quit **아님**) · **`:wq`** = 저장+종료 (1-15) |

**짝:** **`U`** = **U**ndo — **현재 줄** 변경 **전부** 되돌림 · **`p`** = **p**ut (1-10).

## 유형 3. 명령줄·설정 빈칸 (여러 줄)

> **vim 시퀀스·치환 조각** (공지: source codes)

---

### 3-1 (PDF · dd → p)
**상황:** 3줄 파일. 커서 **2번째 줄** · **`dd`** → 커서 **1번째 줄** · **`p`**.

```
Line1
Line2
Line3
```

**문제:** 최종 **3줄** 내용? (순서대로)

**정답:**

```
Line1
Line2
Line3
```

**해설:** `dd`로 **Line2** cut → 1줄만 남음 → `p`가 **Line1 아래**에 Line2 삽입 → **원래와 동일 순서**.

---

### 3-2 (PDF · yy → p)
**상황:** 커서 **1번째 줄** · **`yy`** → **3번째 줄**로 이동 · **`p`**.

```
AAA
BBB
CCC
```

**문제:** 최종 내용?

**정답:**

```
AAA
BBB
CCC
AAA
```

**해설:** `yy` = AAA 복사 · `p` = **커서(CCC) 아래**에 AAA 추가.

---

### 3-3 (PDF slide 13 · 줄 범위 치환)
**상황:**

```
line1 old
line2 old old
line3 old
```

Command: **`:2s/old/new/g`**

**문제:** **3줄** 내용?

**정답:**

```
line1 old
line2 new new
line3 old
```

**해설:** **2행만** 치환 · **`g`** = 그 줄 안 **전부** · **`%`** 아님 → 1·3행 **그대로**.

---

### 3-4 (PDF slide 13 · substitute)
**상황:** 파일 2줄:

```
I am fine
I am fine
```

Command mode: **`: %s/am/is/`** ( **`g` 없음** )

**문제:** **각 줄** 내용?

**정답:** **`I is fine`** (두 줄 **동일**)

**해설 — `%` vs `g` (`1-13` · PDF slide 13):**

| 기호 | 의미 |
|------|------|
| **`%`** | **어느 줄** — `%` = **파일 전체** |
| **`g`** | **한 줄 안 몇 번** — 없으면 **줄마다 첫 번째만** |

**`: %s/am/is/`** (`g` 없음) = **모든 줄** · **각 줄 첫 `am`만** → 이 문제 줄당 `am` 1개 → **두 줄 모두 `I is fine`**.

**`g` 없음 ≠ 1행만** — 한 줄에 `am` 2번일 때:

| 명령 | `I am am fine` |
|------|----------------|
| **`: %s/am/is/`** | **`I is am fine`** (첫 am만) |
| **`: %s/am/is/g`** | **`I is is fine`** (전부) |

---

### 3-5 (`history 2.sh` · global substitute)
**상황:** 3줄 모두 `This is good`.

```vim
:%s/is/was/g
```

**문제:** **한 줄** 내용?

**정답:** **`This was good`**

**해설:** **`is`→`was`** · **`g`** = 줄 안 **전부** (여기 1개).

---

### 3-6 (저장·종료 시퀀스)
**상황:** Insert에서 편집 후 **저장하고 vim 종료**.

```vim

:______
```

**정답:** **`wq`**

**해설:** **Esc** → Normal → **`:wq`**. **`:x`** 도 save+quit (`history 2.sh`).

**문제:** **5~7행만** 치환 · **`%`** 와 차이?

**정답:** **5·6·7행** (5~7 **범위**) · **`%`** = **파일 전체**

**해설 — `5,7` ≠ 5행·7행만 (`3-3` · PDF slide 13):**

| 표기 | 의미 |
|------|------|
| **`:5,7s/old/new/g`** | **5행부터 7행까지** (= **5·6·7** 세 줄) |
| **`: %s/old/new/g`** | **전체** 줄 (`%` = all) |

→ vim에서 **`,`** = **~까지 범위** · **5,7** = 5행과 7행 **사이 전부** (6행 포함).

**예 (10줄 파일):**

| 명령 | 치환되는 줄 |
|------|-------------|
| **`:5,7s/old/new/g`** | **5, 6, 7** 행만 |
| **`:5s/old/new/g`** | **5행**만 (`3-3`의 `:2s/…`) |
| **`: %s/old/new/g`** | **1~끝** 전부 |
