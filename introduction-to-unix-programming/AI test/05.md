## 1. 개념·OX (PDF)

### 1-1
**묻는 것:** mounting이란?

**문제:** Linux는 모든 미디어 디스크를 **하나의 가상 디렉터리**로 묶는다. 새 디스크를 쓰려면 가상 디렉터리 **안의 한 위치에 연결**해야 하는데, 이 작업을 한 단어로 쓰시오.

**정답:** **mounting** (마운트)

**해설:** PDF "Monitoring Disk Space". 디스크를 **마운트 포인트**에 붙여야 파일처럼 접근할 수 있습니다.

---

### 1-2
**묻는 것:** `mount` 출력 4가지 정보

**문제:** `mount` 명령 출력에서 확인할 수 있는 정보 **4가지**를 쓰시오.

**정답:**  
(1) **장치 위치** (device location)  
(2) **마운트 포인트** (virtual directory 상의 위치)  
(3) **파일시스템 타입** (filesystem type)  
(4) **접근 상태** (access status, 예: rw, ro)

**해설:** PDF "The mount command". 예: `/dev/sdb1 on /media/disk type vfat (rw,...)`

---

### 1-3
**묻는 것:** 파일시스템 종류

**문제:** 아래 설명에 맞는 파일시스템 이름을 쓰시오.  
(1) Microsoft Windows PC에서 포맷한 USB에 흔히 보이는 타입  
(2) Windows NT/XP/Vista용 고급 파일시스템  
(3) 표준 CD-ROM 파일시스템

**정답:** (1) **`vfat`** (2) **`ntfs`** (3) **`iso9660`**

**해설:** PDF slide 5. USB 예시에서 `/dev/sdb1 ... type vfat`가 Windows 포맷을 의미합니다.

---

### 1-4
**묻는 것:** umount 전에 해야 할 일

**문제:** 이동식 미디어(USB 등)를 빼기 **전에** 반드시 해야 하는 작업은?

**정답:** **`umount`** (언마운트)

**해설:** PDF "The unmount command". 마운트 해제 없이 물리적으로 빼면 데이터 손상 위험이 있습니다.

---

### 1-5
**묻는 것:** `df` vs `du`

**문제:**  
(1) **파일시스템(장치) 단위** 여유 공간을 보려면 **`df`** / **`du`** 중 어느 것?  
(2) **특정 디렉터리**가 차지하는 용량을 보려면 **`df`** / **`du`** 중 어느 것?

**정답:** (1) **`df`** (2) **`du`**

**해설:** PDF·`history 5.sh`. `df` = disk **free**, `du` = disk **usage**.

---

### 1-6
**묻는 것:** grep / egrep / fgrep

**문제:**  
(1) **고정 문자열**(메타문자 해석 없음)만 매칭할 때 쓰는 명령은?  
(2) **POSIX 확장 정규식**(`|`, `..` 등)을 쓸 때 쓰는 명령은?  
(3) `grep "." file` 과 `fgrep "." file` 중 **`.`을 글자 그대로** 찾는 것은?

**정답:** (1) **`fgrep`** (2) **`egrep`** (3) **`fgrep "." file`**

**해설:** PDF slide 4<. `grep "."` → 모든 줄(`.`=임의 한 글자). `fgrep "."` → **점(.)이 들어간 줄만**.

---

### 1-7
**묻는 것:** bzip2 / gzip 압축 후 내용 보기

**문제:** `.bz2` 파일 내용을 **압축 해제 없이** 화면에 보려면? `.gz` 파일은?

**정답:** **`bzcat`** / **`gzcat`** (또는 `zcat`)

**해설:** PDF. 압축 텍스트는 `cat`·`less`로 바로 못 읽고 **전용 cat** 명령을 씁니다.

## 2. 명령·옵션 빈칸 채우기

> **「이런 일을 하려고 할 때, 빈칸에 뭐가 들어가야 할까?」**

---

### 2-1 (mount 기본)
**상황:** 현재 시스템에 **마운트된 모든 장치 목록**을 본다.

**문제:** 빈칸을 채우시오.

```bash
______
```

**정답:** `mount`

**해설:** 인자 없이 `mount`만 실행하면 목록 출력. `history 5.sh`와 동일.

---

### 2-2 (mount -t)
**상황:** Windows에서 포맷한 USB **`/dev/sdb1`** 을 **`/media/disk`** 에 **수동 마운트**한다. 파일시스템 타입은 vfat.

**문제:** 빈칸 3개를 채우시오.

```bash
mount -t ______ /dev/sdb1 ______
```

**정답:** `vfat` / `/media/disk`

**해설:** PDF slide 6. 형식: `mount -t [타입] [장치] [마운트포인트]`. `history 5.sh` 주석과 같습니다.

---

### 2-3 (mount -o)
**상황:** `.iso` CD 이미지 **파일**을 loop 방식으로 마운트한다.

**문제:** 빈칸을 채우시오. (옵션 이름)

```bash
mount -o ______ image.iso /mnt/iso
```

**정답:** `loop` (필요 시 `ro,loop` 등과 함께)

**해설:** PDF slide 7~8. `-o loop` = **파일을 블록 장치처럼** 마운트.

---

### 2-4 (mount -o 옵션)
**상황:** 파일시스템을 **읽기 전용**으로 마운트한다.

**문제:** `-o` 뒤에 쓸 옵션은?

**정답:** **`ro`**

**해설:** PDF. `rw`=read-write, `ro`=read-only, `user`=일반 사용자 마운트 허용, `check=none`=무결성 검사 생략.

---

### 2-5 (umount)
**상황:** `/media/disk` 에 마운트된 USB를 **해제**한다.

**문제:** 빈칸을 채우시오.

```bash
______ /media/disk
```

**정답:** `umount`

**해설:** PDF·`history 5.sh`. 철자는 **`umount`** (un**mount**가 아님). 장치명(`/dev/sdb1`) 또는 디렉터리 중 하나 지정.

---

### 2-6 (df)
**상황:** 각 파일시스템의 **여유·사용 공간**을 **사람이 읽기 쉬운 단위**(M, G)로 본다.

**문제:** 빈칸을 채우시오.

```bash
df ______
```

**정답:** `-h`

**해설:** PDF "df -h", `history 5.sh` "Human-readable". **Mounted on** 열에서 어느 경로에 붙었는지 확인.

---

### 2-7 (du)
**상황:** 현재 디렉터리 **전체 합계** 용량만 한 줄로, 단위는 읽기 쉽게 본다.

**문제:** 빈칸을 채우시오.

```bash
du ______
```

**정답:** `-sh`

**해설:** `-s` = summarize, `-h` = human-readable. `history 5.sh`: `du -sh`.

---

### 2-8 (du + sort)
**상황:** 현재 디렉터리 **각 항목** 용량을 구한 뒤, **큰 것부터** 정렬해 본다.

**문제:** 빈칸 2개를 채우시오.

```bash
du -sh * | sort ______
```

**정답:** `-hr` (또는 `-h -r`)

**해설:** `history 5.sh`: `du -sh * | sort -hr`. `-h` = human numeric sort, `-r` = reverse(내림차순).

---

### 2-9 (sort /etc/passwd)
**상황:** `/etc/passwd`를 **콜론(`:`) 구분**, **3번째 필드(uid, 숫자)** 기준으로 정렬한다.

**문제:** 빈칸 3개를 채우시오.

```bash
sort -t ':' -k 3 ______ /etc/passwd
```

**정답:** `-n`

**해설:** PDF·`history 5.sh`. `-t` = 구분자, `-k` = 필드 번호, `-n` = numeric.

---

### 2-10 (sort 내림차순)
**상황:** `du` 출력을 **내림차순**으로 정렬해 **가장 큰 파일/폴더**를 위에 두고 싶다.

**문제:** 빈칸을 채우시오.

```bash
du -sh * | sort -h ______
```

**정답:** `-r`

**해설:** PDF slide <5. `-r` = reverse.

---

### 2-11 (grep)
**상황:** `file1`에서 **`t`를 포함하지 않는** 줄만 출력한다.

**문제:** 빈칸을 채우시오.

```bash
grep ______ t file1
```

**정답:** `-v`

**해설:** PDF·`history 5.sh`. `-v` = invert.

---

### 2-12 (grep)
**상황:** `file1`에서 `t`가 있는 줄을 **줄 번호와 함께** 출력한다.

**문제:** 빈칸을 채우시오.

```bash
grep ______ t file1
```

**정답:** `-n`

**해설:** PDF 예: `2:two`, `3:three`.

---

### 2-13 (grep)
**상황:** `file1`에서 **`t` 또는 `f`** 를 포함한 줄을 찾는다. (한 명령, `-e` 사용)

**문제:** 빈칸을 채우시오.

```bash
grep -e t ______ f file1
```

**정답:** `-e`

**해설:** `grep -e t -e f file1` = `grep '[tf]' file1` 과 유사.

---

### 2-14 (grep 빈 줄)
**상황:** 파일 내용에서 **빈 줄을 제외**하고 출력한다.

**문제:** 빈칸·패턴을 채우시오.

```bash
grep -v '______' file_name
```

**정답:** `^$`

**해설:** PDF·`history 5.sh`. `^` = 줄 시작, `$` = 줄 끝 → `^$` = 빈 줄.

---

### 2-15 (grep 재귀 — history 5 그대로)
**상황:** **현재 디렉터리 이하 전체**에서 `two`가 들어간 줄을 찾는다. (수업에서 쓴 패턴)

**문제:** 빈칸·패턴을 채우시오.

```bash
grep -R "______" .
```

**정답:** `.*two` (전체: `grep -R ".*two" .`)

**해설:** `history 5.sh` 47행 그대로. `-R` = recursive, `.*two` = 앞에 아무 문자나 온 뒤 `two`.

---

### 2-16 (bzip2)
**상황:** `myprog.bz2`를 **원래 파일로 복원**한다.

**문제:** 빈칸을 채우시오.

```bash
______ myprog.bz2
```

**정답:** `bunzip2`

**해설:** PDF. `bzip2` = 압축, `bunzip2` = 해제, `bzcat` = 내용 보기.

---

### 2-17 (gzip)
**상황:** `myprog.gz`를 **압축 해제**한다.

**문제:** 빈칸을 채우시오.

```bash
______ myprog.gz
```

**정답:** `gunzip`

**해설:** PDF·`history 4.sh`. `gzip` = 압축, `gunzip` = 해제.

---

### 2-18 (tar 생성)
**상황:** `test/`, `test2/` 디렉터리를 **`test.tar`** 아카이브로 **만든다**. (verbose)

**문제:** 빈칸을 채우시오.

```bash
tar -______ test.tar test/ test2/
```

**정답:** `cvf`

**해설:** PDF. `c`=create, `v`=verbose, `f`=file name.

---

### 2-19 (tar 목록)
**상황:** `test.tar` **내용 목록만** 보고, **추출하지 않는다**.

**문제:** 빈칸을 채우시오.

```bash
tar -______ test.tar
```

**정답:** `tf`

**해설:** `t` = list, `f` = file.

---

### 2-20 (tar 추출 + gzip)
**상황:** **`filename.tgz`** (gzip된 tar)를 **현재 디렉터리에 풀**고, 진행 과정을 출력한다.

**문제:** 빈칸을 채우시오.

```bash
tar -______ filename.tgz
```

**정답:** `zxvf`

**해설:** PDF slide 49. `z`=gzip, `x`=extract, `v`=verbose, `f`=file. `history 4.sh`: `tar -xvzf`.

---

### 2-21 (tar + gzip 한 번에 생성 — history 4)
**상황:** 현재 디렉터리 **모든 항목**을 **`archiv.tar.gz`** 로 **압축 아카이브** 생성. (수업 실습)

**문제:** 빈칸을 채우시오.

```bash
tar -______ archiv.tar.gz *
```

**정답:** `cvzf`

**해설:** `history 4.sh`: `tar -cvzf archiv.tar.gz *`. `c` + `z` + `v` + `f`.

---

### 2-22 (du + sort + more)
**상황:** 현재 디렉터리 **하위 항목별** 용량을 구한 뒤, **정렬**하고 **한 화면씩** 본다.

**문제:** 빈칸을 채우시오.

### 2-23 (egrep — history 5)

---

### 2-24 (Shell 변수)

**해설:** `history 5.sh` 75행. `export test` 후 `bash`로 자식 쉘에 들어가도 `$test` 사용 가능.

## 3. 결과 예측 — 명령 출력·동작

### 3-1 (grep t)
**상황:** `file1` 내용

```
one
two
three
four
five
```

**문제:** `grep t file1` 출력 줄은? (순서대로)

**정답:**

```
two
three
```

**해설:** PDF slide <7. `t` **포함** 줄만. `one`, `four`, `five`는 제외.

---

### 3-2 (grep -v t)
**상황:** 3-1과 같은 `file1`.

**문제:** `grep -v t file1` 출력은?

**정답:**

```
one
four
five
```

**해설:** `-v` = 매칭 **아닌** 줄.

---

### 3-3 (grep -n t)
**상황:** 3-1과 같은 `file1`.

**문제:** `grep -n t file1` 출력 2줄을 쓰시오.

**정답:**

```
2:two
3:three
```

**해설:** PDF 예시와 동일.

---

### 3-4 (grep [tf])
**상황:** 3-1과 같은 `file1`.

**문제:** `grep [tf] file1` 출력 줄은? (몇 줄?)

**정답:** **4줄** — `two`, `three`, `four`, `five`

**해설:** `[tf]` = **t 또는 f** 한 글자. `one`은 t,f 둘 다 없음. `grep tf`와 다름!

---

### 3-5 (sort 숫자 — Lecture/file2)
**상황:** `Lecture/file2` 내용 (`history 5.sh` 실습 파일):

```
1
100
2
200
145
```

**문제:**  
(1) `sort file2` 결과 **처음 세 줄**은?  
(2) `sort -n file2` 결과 **전체 순서**는?

**정답:**  
(1) **`1`, `100`, `145`** (문자열/사전순 — `100`이 `2`보다 앞)  
(2) **`1`, `2`, `100`, `145`, `200`** (숫자순)

**해설:** `history 5.sh` 28~32행. 주석의 `1, 100, 2, 20`은 설명용 예시이고, **실제 file2**는 위 5줄입니다.

---

### 3-6 (bzip2)
**상황:**

```bash
ls -l myprog          # 4882 bytes
bzip2 myprog
ls -l myprog.bz2      # 2378 bytes
```

**문제:**  
(1) `myprog` 원본 파일은 bzip2 직후 **남아 있는가?** (O/X)  
(2) `bunzip2 myprog.bz2` 후 원본 크기는 **4882** 로 돌아오는가? (O/X)

**정답:** **X** / **O**

**해설:** PDF. `bzip2`는 원본을 **`.bz2`로 바꿈**(원본 삭제). `bunzip2`로 복원.

## 5. 표 완성 (PDF 핵심)

**문제:** 설명 칸을 채우시오.

| 명령 | 설명 (빈칸) |
|------|-------------|
| `mount` | |
| `mount -t vfat /dev/sdb1 /media/disk` | |
| `umount /media/disk` | |
| `df -h` | |
| `du -sh` | |
| `sort -t ':' -k 3 -n /etc/passwd` | |
| `grep -v '^$' file` | |
| `bzip2 file` | |
| `tar -cvf a.tar dir/` | |
| `tar -zxvf a.tgz` | |

---

**정답·해설**

| 명령 | 설명 (시험에 적을 분량) |
|------|-------------------------|
| `mount` | **마운트 목록** 표시 (인자 없을 때) |
| `mount -t vfat /dev/sdb1 /media/disk` | vfat USB를 **장치→마운트포인트**에 **수동 마운트** |
| `umount /media/disk` | 해당 마운트 **해제** |
| `df -h` | 파일시스템 **여유 공간**, **읽기 쉬운 단위** |
| `du -sh` | **현재(또는 지정) 디렉터리** 사용량 **합계** |
| `sort -t ':' -k 3 -n /etc/passwd` | `:` 구분 **3번 필드(uid) 숫자** 정렬 |
| `grep -v '^$' file` | **빈 줄 제외** 출력 |
| `bzip2 file` | **`.bz2`로 압축** (원본 대체) |
| `tar -cvf a.tar dir/` | tar **생성**, verbose |
| `tar -zxvf a.tgz` | gzip tar **추출** |

**mount -o 자주 나오는 옵션**

| 옵션 | 의미 |
|------|------|
| `ro` | 읽기 전용 |
| `rw` | 읽기·쓰기 |
| `user` | 일반 사용자 마운트 허용 |
| `loop` | **파일**을 장치처럼 마운트 (.iso 등) |
| `check=none` | 무결성 검사 생략 |

**압축·아카이브 도구**

| 작업 | bzip2 계열 | gzip 계열 | tar |
|------|------------|-----------|-----|
| 압축 | `bzip2` | `gzip` | `-c` + `-z`(gzip) |
| 해제 | `bunzip2` | `gunzip` | `-x` + `-z` |
| 내용 보기 | `bzcat` | `gzcat` | `-t` (목록) |

## 자주 헷갈리는 것 (05)

| 헷갈림 | 정리 |
|--------|------|
| `df` vs `du` | **장치 여유** vs **디렉터리 사용량** |
| `umount` vs `unmount` | 정식 명령은 **`umount`** |
| `grep "."` vs `fgrep "."` | **모든 줄** vs **점(.) 글자만** |
| `grep [tf]` vs `grep tf` | **t 또는 f** vs **문자열 tf** |
| `sort` vs `sort -n` | **사전순** (`100` < `2`) vs **숫자순** |
| `bzip2`/`gzip` 후 원본 | **사라짐** (`.bz2`/`.gz`로 대체) |
| `tar -tf` vs `tar -xf` | **목록** vs **추출** |
| `mount` 인자 순서 | `-t 타입 **장치** **마운트포인트**` |
| device is busy | **사용 중**이면 umount 실패 — cd로 빠져나온 뒤 재시도 |
| `history 5` 주석 vs `file2` | 주석 `1,100,2,20`은 설명용 — **시험·실습은 Lecture/file2** (200, 145 포함) |
| `export` 없이 `bash` | 자식 쉘에서 **지역 변수 안 보임** |
| `grep -R "two"` vs `".*two"` | 수업은 **`grep -R ".*two" .`** (`history 5.sh`) |
