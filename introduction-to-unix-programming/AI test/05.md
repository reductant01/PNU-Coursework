## 유형 1. 개념 O/X

> **목표:** 틀리면 안 되는 **개념**부터 잡기. ( O / X )

---

### 1-1
**문제:** Linux는 HDD·USB·CD 등을 **하나의 가상 디렉터리 트리**로 묶어 본다. ( O / X )

**정답:** **O**

**해설:** mounting = “이 디스크를 **어느 폴더 아래에** 보이게 할지 정해 붙이기”.

---

### 1-2
**문제:** 디스크를 트리 **안의 한 디렉터리에 연결**하는 작업을 **mounting**(마운트)이라 한다. ( O / X )

**정답:** **O**

**해설:** 연결되는 디렉터리를 **마운트 포인트**(mount point)라 부른다.

---

### 1-3
**문제:** 연결하기 **전**에는 `/dev/sdb1` 같은 장치 파일만 있고, `/media/disk` 아래에는 **아직** 그 디스크 파일이 보이지 않는다. ( O / X )

**정답:** **O**

**해설:** `mount` 후에야 마운트 포인트 아래에서 디스크 내용에 접근한다.

---

### 1-4
**문제:** Windows PC에서 포맷한 USB를 Linux에 붙이면 `mount` 출력의 `type` 뒤에 **`vfat`** 가 자주 나온다. ( O / X )

**정답:** **O**

**해설:** **vfat** = Virtual FAT — MS Windows와 호환되는 FAT 계열(USB에 흔함).

---

### 1-5
**문제:** **`df`**는 파일시스템(장치) **여유 공간**, **`du`**는 **디렉터리·파일 사용량**을 본다. ( O / X )

**정답:** **O**

**해설:** **d**isk **f**ree vs **d**isk **u**sage. `df -h`의 **Mounted on** = 마운트 포인트.

---

### 1-6
**문제:** `umount` 시 **`device is busy`** 는 해당 마운트 포인트를 **쓰는 프로세스**가 있을 때 날 수 있다. ( O / X )

**정답:** **O**

**해설:** 현재 작업 디렉터리가 그 안이면 해제 불가 — **cd로 나간 뒤** 재시도.

---

### 1-7
**문제:** umount 없이 USB를 물리적으로 빼도 **데이터 손상 위험이 없다**. ( O / X )

**정답:** **X**

**해설:** **마운트 → 사용 → umount → 분리** 순서.

---

### 1-8
**문제:** 마운트 해제 명령의 정식 철자는 **`unmount`** 이다. ( O / X )

**정답:** **X**

**해설:** 정식 명령은 **`umount`** (un**mount**가 아님).

---

### 1-9
**문제:** `bzip2`·`gzip`은 보통 원본을 **`.bz2`/`.gz`로 바꾸고** 원본 파일을 **지운다**. ( O / X )

**정답:** **O**

**해설:** `bunzip2`·`gunzip`으로 복원. 풀지 않고 보려면 `bzcat`·`gzcat`.

---

### 1-10
**문제:** `grep "."` 과 `fgrep "."` 은 **같은 줄**만 출력한다. ( O / X )

**정답:** **X**

**해설:** `grep "."` = 정규식(임의 한 글자) → 내용 있는 줄 **전부**. `fgrep "."` = **점 문자**만 → 점 있는 줄만.

---

### 1-11
**문제:** `grep [tf] file1` 과 `grep tf file1` 은 **같은 결과**다. ( O / X )

**정답:** **X**

**해설:** `[tf]` = **t 또는 f 한 글자**. `tf` = **문자열 "tf"** 연속.

---

### 1-12
**문제:** `sort file2` 기본 정렬에서 **`100`이 `2`보다 앞**에 온다(사전순). ( O / X )

**정답:** **O**

**해설:** 숫자 크기순은 **`sort -n`**. `history 5.sh`·`Lecture/file2` 참고.

---

### 1-13
**문제:** `tar -tf` 는 아카이브 **목록만** 보고, **추출하지 않는다**. ( O / X )

**정답:** **O**

**해설:** 추출 = `-x`. 목록 = `-t`.

---

### 1-14
**문제:** `mount -t vfat /dev/sdb1 /media/disk` 에서 인자 순서는 **타입 → 장치 → 마운트포인트** 이다. ( O / X )

**정답:** **O**

**해설:** `-t` = **t**ype(파일시스템 타입 지정).

---

### 1-15
**문제:** `export` 없이 `bash`로 자식 쉘에 들어가도 **지역 변수** `$test`가 그대로 보인다. ( O / X )

**정답:** **X**

**해설:** `export test` 후에만 자식 쉘·프로세스에 전달.

---

### 1-16
**문제:** `grep -v '^$' file` 은 **빈 줄을 제외**하고 출력한다. ( O / X )

**정답:** **O**

**해설:** `^$` = 줄 맨 앞·끝 사이 글자 없음(빈 줄). `-v` = in**v**ert.

---

### 1-17
**문제:** `df -h | grep '/$'` 는 **Mounted on이 `/`인 줄**(루트 파티션)을 고른다. ( O / X )

**정답:** **O**

**해설:** `$` = 줄 **끝** 위치.

---

### 1-18
**문제:** `bunzip2` = **b**zip **un**compress 로 **복원**한다. ( O / X )

**정답:** **O**

**해설:** §2-16·압축 표 참고.

---

### 1-19
**문제:** `tar -cvzf` 의 **`-z`** 는 **gzip 압축**을 의미한다. ( O / X )

**정답:** **O**

**해설:** `history 4.sh`: `tar -cvzf archiv.tar.gz *`.

---

### 1-20
**문제:** `history 5.sh` 주석의 `1,100,2,20` 과 **`Lecture/file2`** (`1,100,2,200,145`) 는 **같은 파일**이다. ( O / X )

**정답:** **X**

**해설:** 주석은 설명용 예시 — **시험·실습은 Lecture/file2** 기준.

---

### 1-21
**문제:** `grep -c` 옵션은 **매칭된 줄의 개수만** 출력한다(줄 내용은 안 보임). ( O / X )

**정답:** **O**

**해설:** PDF 05 `grep -c`. `-n` = 줄 번호+내용 · `-c` = **count**(개수만).

## 유형 2. 명령·옵션 빈칸

> **「이런 일을 할 때 빈칸에 뭐?」**

---

### 2-1
**상황:** 현재 시스템에 **마운트된 모든 장치 목록**을 본다.

```bash
______
```

**정답:** `mount`

**해설:** 인자 없이 `mount`만 실행하면 목록 출력. `history 5.sh`와 동일.

---

### 2-2
**상황:** Windows USB **`/dev/sdb1`** → **`/media/disk`** 수동 마운트 (vfat).

```bash
mount -t ______ /dev/sdb1 ______
```

**정답:** `vfat` / `/media/disk`

**해설:** `mount -t [타입] [장치] [마운트포인트]`. `-t` = **t**ype.

---

### 2-3
**상황:** `.iso` CD 이미지 **파일**을 loop 방식으로 마운트.

```bash
mount -o ______ image.iso /mnt/iso
```

**정답:** `loop` (필요 시 `ro,loop` 등)

**해설:** `-o` = **o**ptions. `loop` = 파일을 블록 장치처럼 마운트.

---

### 2-4
**상황:** 파일시스템을 **읽기 전용**으로 마운트.

**문제:** `-o` 뒤에 쓸 읽기 전용 옵션은?

**정답:** **`ro`**

**해설:** `ro` = read-only · `rw` = read-write.

---

### 2-5
**상황:** `/media/disk` 에 마운트된 USB **해제**.

```bash
______ /media/disk
```

**정답:** `umount`

**해설:** 장치명(`/dev/sdb1`) 또는 디렉터리 중 하나 지정.

---

### 2-6
**상황:** 파일시스템 **여유·사용 공간**을 **읽기 쉬운 단위**로.

```bash
df ______
```

**정답:** `-h`

**해설:** **d**isk **f**ree. `-h` = **h**uman-readable.

---

### 2-7
**상황:** 현재 디렉터리 **전체 합계** 용량만 한 줄, 읽기 쉬운 단위.

```bash
du ______
```

**정답:** `-sh`

**해설:** `-s` = **s**ummarize · `-h` = **h**uman-readable.

---

### 2-8
**상황:** 현재 디렉터리 **각 항목** 용량 후 **큰 것부터** 정렬.

```bash
du -sh * | sort ______
```

**정답:** `-hr` (또는 `-h -r`)

**해설:** `history 5.sh`: `du -sh * | sort -hr`. `-r` = reverse(내림차순).

---

### 2-9
**상황:** `/etc/passwd`를 **콜론(`:`) 구분**, **3번째 필드(uid, 숫자)** 기준 정렬.

```bash
sort -t ':' -k 3 ______ /etc/passwd
```

**정답:** `-n`

**해설:** `-t` = separa**t**or · `-k` = **k**ey · `-n` = **n**umeric.

---

### 2-10
**상황:** `du` 출력 **내림차순** 정렬.

```bash
du -sh * | sort -h ______
```

**정답:** `-r`

**해설:** `-r` = reverse.

---

### 2-11
**상황:** `file1`에서 **`t`를 포함하지 않는** 줄만.

```bash
grep ______ t file1
```

**정답:** `-v`

**해설:** `-v` = in**v**ert(매칭 **제외**).

---

### 2-12
**상황:** `file1`에서 `t`가 있는 줄을 **줄 번호와 함께**.

```bash
grep ______ t file1
```

**정답:** `-n`

**해설:** `-n` = line **n**umber → `2:two` 형식.

---

### 2-13
**상황:** `file1`에서 **`t` 또는 `f`** (한 명령, `-e` 사용).

```bash
grep -e t ______ f file1
```

**정답:** `-e`

**해설:** `-e` = **e**xpression. `grep t f`는 `f`가 **파일**로 해석됨.

---

### 2-14
**상황:** 파일에서 **빈 줄 제외**.

```bash
grep -v '______' file_name
```

**정답:** `^$`

**해설:** `^` = 줄 맨 앞 · `$` = 줄 맨 끝 → 사이 글자 없음 = 빈 줄.

---

### 2-15
**상황:** **현재 디렉터리 이하 전체**에서 `two` 검색 (`history 5.sh`).

```bash
grep -R "______" .
```

**정답:** `.*two` (전체: `grep -R ".*two" .`)

**해설:** `-R` = **R**ecursive. 수업·`history 5.sh` 47행 패턴.

---

### 2-16
**상황:** `myprog.bz2` **원래 파일로 복원**.

```bash
______ myprog.bz2
```

**정답:** `bunzip2`

**해설:** `bzip2` = 압축 · `bunzip2` = 해제 · `bzcat` = 내용 보기.

---

### 2-17
**상황:** `myprog.gz` **압축 해제**.

```bash
______ myprog.gz
```

**정답:** `gunzip`

**해설:** `history 4.sh`. `gzip` = 압축 · `gunzip` = 해제.

---

### 2-18

### 2-27 (명령 ↔ 역할 — 표 완성)

| `tar -zxvf a.tgz` | gzip tar **추출** |
