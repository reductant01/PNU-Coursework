## 유형 1. 개념 O/X

---

### 1-1
**문제:** `for var in list` 에서 **list** 의 **각 값마다** `do`~`done` 블록이 **1번** 실행된다. ( O / X )

**정답:** **O**

**해설:** `for city in Seoul Busan Daegu` → **3개** 값마다 `do`~`done` **1번** (`Seoul` → `Busan` → `Daegu`).

---

### 1-2
**문제:** `for` 루프가 **끝난 뒤**에도 루프 변수는 **마지막 반복 값**을 유지한다(다시 대입하지 않으면). ( O / X )

**정답:** **O**

**해설:** PDF slide 4 — `$test` 가 **마지막 값** 유지.

---

### 1-3
**문제:** `for x in 'I don't'` 처럼 목록 안 **작은따옴표**가 있으면 **이스케이프(`\'`)** 또는 **큰따옴표로 감싸기**가 필요할 수 있다. ( O / X )

**정답:** **O**

**해설:** `'I don't'` → 안의 **`'`** 가 문자열을 **끊음** (문법 오류).

| | **`'…'`** | **`"…"`** |
|--|----------|----------|
| `don't` 안 `'` | **문제** | **OK** |

→ **`for x in "I don't"`** 또는 **`'I don'\''t'`** (PDF slide 5~6).

---

### 1-4
**문제:** `list=$list" four five"` 는 기존 문자열 **뒤에** 단어를 **붙이는(concatenate)** 방법이다. ( O / X )

**정답:** **O**

**해설:** `list="one two three"` → `list=$list" four five"` → **`one two three four five`** (`$list` + `" four five"` 이어 붙임 · `""`만이 아님).

→ `for test in $list` = **5번** (`one`~`five` · `forTest.sh`).

---

### 1-5
**문제:** `` for f in `cat file` `` 는 **명령 결과**를 for **목록**으로 쓴다. ( O / X )

**정답:** **O**

**해설:** PDF slide 9 · `14.md` 3-9.

---

### 1-6
**문제:** **IFS** 기본값에는 **공백·탭·줄바꿈**이 포함된다. ( O / X )

**정답:** **O**

**해설:** **IFS** = **I**nternal **F**ield **S**eparator · `for` 목록 **자르는 규칙** · 기본 = **공백·탭·줄바꿈**.

---

### 1-7
**문제:** `IFS=$'\n'` 은 for가 목록을 자를 때 **줄바꿈에서만** 끊게 한다. ( O / X )

**정답:** **O**

**해설:** `IFS=$'\n'` → **줄바꿈에서만** 자름 (공백·탭 무시 · `15.md` 4-6).

| 설정 | 구분자 |
|------|--------|
| `IFS=$'\n'` | 줄바꿈 (`$'\n'` = Enter 한 글자) |
| `IFS=:` | 콜론 (`/etc/passwd` · `forTest.sh`) |
| `IFS=$'\t'` | 탭 |
| `IFS=$'\n':;"` | 줄바꿈+`:`+`;`+`"` (PDF) — **`:` 등은 `$'…'` 밖에** 그냥 붙임 |

**`$'\n'` vs `'\n'`:** 후자는 `\`+`n` 두 글자 · 전자만 **진짜 줄바꿈**.

---

### 1-8
**문제:** 긴 스크립트에서 IFS를 바꾼 뒤 **`IFS=$IFS.OLD`** 로 **원래 값**을 되돌리는 것이 안전하다. ( O / X )

**정답:** **O**

**해설:** PDF slide 11.

```bash
IFS.OLD=$IFS
IFS=$'\n'
# …
IFS=$IFS.OLD
```

---

### 1-9
**문제:** `/etc/passwd` 를 **필드 단위**로 자르려면 **`IFS=:`** 를 쓸 수 있다. ( O / X )

**정답:** **O**

**해설:** **필드(field)** = 한 줄을 **구분자로 나눈 한 칸** · `/etc/passwd` 는 **`:`** 로 구분.

```
root:x:0:0:root:/root:/bin/bash
```

`IFS=:` 후 `for f in $line` → **`root`** · **`x`** · **`0`** · **`0`** … (`forTest.sh` 안쪽 루프).

---

### 1-10
**문제:** `for file in $HOME/*` 에서 `*` 는 **glob**(와일드카드)으로 **파일 이름을 펼친다**. ( O / X )

**정답:** **O**

**해설:** PDF slide 12 — file globbing.

---

### 1-11
**문제:** `for` 목록에 **실제로 없는 경로**를 넣어도, 쉘은 **에러 없이** 그 **글자 그대로** 한 번 반복할 수 있다. ( O / X )

**정답:** **O**

**해설:** `for` 는 목록을 **미리 존재 검사 안 함** (PDF slide 13).

```bash
for item in /no/such/dir/*
do echo "$item"
done
# 폴더 없으면 → /no/such/dir/* 그대로 1번 (glob 안 펼쳐짐)
```

→ **있는지 확인 안 함** · 처리 전 **`[ -e "$item" ]`** 권장.

**왜 `"$item"` 처럼 큰따옴표?** (안 넣은 예도 있음)

```bash
[ -e $item ]       # 경로에 공백 없으면 보통 동작
[ -e "$item" ]     # 경로·파일 검사할 때 **권장** (forTest.sh · 15.md)
```

| `item` 값 | `[ -e $item ]` | `[ -e "$item" ]` |
|-----------|----------------|------------------|
| `/home/sj/file` | OK | OK |
| `/home/sj/my file` (공백) | **깨짐** (두 덩어리로 쪼개짐) | **OK** |

→ **`$` 는 변수 값** · **`""` 는 그 값을 한 덩어리로** (공백·`*` 보호) · **안 써도 되는 경우**는 단순 경로뿐 · 시험·실습은 **`"$file"`** 로 통일.

---

### 1-12
**문제:** C-style **`for (( i=1; i<=10; i++ ))`** 에서 조건의 **`i`** 앞에 **`$`를 붙이지 않는다**. ( O / X )

**정답:** **O**

**해설:** C-style for = **`for (( … ))`** (**괄호 2개**가 문법).

**예시 — `( )` vs `(( ))`:**

```bash
# ( ) 한 개 = 서브쉘 (별도 프로세스)
x=1
( x=2 )          # 서브쉘 안만 x=2
echo $x          # → 1  (밖은 안 바뀜)

# (( )) = 산술만 (서브쉘 아님)
x=1
(( x=2 ))        # 바깥 x 변경
echo $x          # → 2

# C-style for — (( )) 필수
for (( i=1; i<=3; i++ )); do echo $i; done   # → 1 2 3
# for ( i=1; i<=3; i++ )   ← 이런 문법 없음 (X)
```

→ **`(( ))` 안** `i` 는 **숫자 계산용 이름** · **`$` 생략** (PDF slide 14).

---

### 1-13
**문제:** `for ((a=1, b=10; a<=5; a++, b+=10))` 처럼 **변수를 여러 개** 쓸 수 있다. ( O / X )

**정답:** **O**

**해설:** PDF slide 14 · `forTest.sh` — `a`·`b` 동시 증가.

---

### 1-14
**문제:** `for i in {1..5}` 는 **1부터 5까지** 펼쳐진 목록과 같다. ( O / X )

**정답:** **O**

**해설:** `forTest.sh` · brace expansion.

---

### 1-15
**문제:** `for test in "Hello World"` 는 **2번** 반복한다 (`Hello` / `World`). ( O / X )

**정답:** **X**

**해설:** **큰따옴표** → **한 덩어리 1번** · `14.md` 1-11.

### 2-8
**상황:** 합계 누적 (`average_with_loops.sh`).

```bash
sum=$((sum ______ i))
```

**정답:** **`+`**

**해설:** **`$(( ))`** = **산술 연산** 결과를 변수에 넣음 (`1-12` `(( ))` 와 같은 계열).

```bash
sum=$((sum + i))    # sum에 i 더한 **숫자** → sum에 대입

# 괄호 1개? — 전혀 다름
sum=$(sum + i)      # $( ) = **명령 실행** 결과 · sum+i 는 명령 아님 → **오류**
( sum + i )         # ( ) = **서브쉘** · 이것도 산술 대입 **아님**
```

**예시 3가지 — 각각 뭐가 일어나나:**

**① `sum=$((sum + i))`** — 숫자 더하기 (`average_with_loops.sh`)

```bash
sum=0
i=3
sum=$((sum + i))    # 0+3 계산 → 5가 아니라 3 · sum=3
echo $sum           # → 3
```

→ **`$(( ))` 안은 수학** · 결과 **숫자**가 `sum`에 들어감.

**② `` x=`date` ``** — **명령** 출력 가져오기 (`$( )` = 백틱과 같음)

```bash
x=$(date)           # date 명령 **실행** → 나온 글자열을 x에 저장
echo $x             # → Mon Jun  8 … (날짜 문자열)
```

→ **`$( )` 안은 명령 이름** · `sum + i` 는 명령이 아니라서 **`$(sum + i)` 불가**.

**③ `( cd /tmp )`** — **서브쉘** (잠깐 다른 프로세스)

```bash
pwd                 # → /home/sj
( cd /tmp )         # **안쪽만** /tmp 로 이동
pwd                 # → /home/sj  (밖은 **안 바뀜**)
```

→ **`( )` 는 폴더 이동·변수 변경을 밖에 안 남김** · 산술 **아님**.

| 기호 | 안에 넣는 것 | 이 문제 `sum+i` |
|------|-------------|-----------------|
| **`$(( ))`** | **숫자 식** | ✅ |
| **`$( )`** | **명령** | ❌ |
| **`( )`** | **명령 묶음** | ❌ (대입도 안 됨) |

| `What a beautiful` | `What` + `a` + `beautiful` → **3조각** | `What a beautiful` → **1조각** |

### 4-6 (`forTest.sh` · C-style 다중 변수)
**상황:** `forTest.sh` — `a`와 `b`를 **한 줄**에서 같이 초기화·증가 (`3-5`는 **초기 `b` 빈칸**).

```bash
for ((a=1, b=10; a<=5; a++, b+=10))
do
  echo "a: $a, b: $b"
done
```

**문제:** 루프가 **끝난 뒤** `a`와 `b`는?

**정답:** **`a=6`** · **`b=60`**

**해설:** `do`~`done` **끝날 때마다** `a++`, `b+=10` (다음 조건 검사 **전**).

| `echo` 시점 (`a`, `b`) | 다음 (`a++`, `b+=10` 후) |
|------------------------|--------------------------|
| 1, 10 | 2, 20 |
| 2, 20 | 3, 30 |
| 3, 30 | 4, 40 |
| 4, 40 | 5, 50 |
| 5, 50 | **6, 60** → `a<=5` 거짓 · **종료** |

### 5-1 (glob · 없는 디렉터리)
**상황:** `/no/such/dir` 폴더는 **없음**.

- **glob** = `*` 같은 **와일드카드**로 **파일 이름을 찾아** 목록으로 바꾸는 것 (`1-10`)
- **펼쳐짐** = `*.txt` → `a.txt` `b.txt` … 여러 항목
- **안 펼쳐짐** = 맞는 파일이 **없어서** `*`가 **글자 그대로** 남음

```bash
for x in /no/such/dir/*
do
  echo "$x"
done
```

**문제:** `echo`는 **몇 번** 실행되며, 출력되는 **`$x`** 는?

**정답:** **1번** · **`/no/such/dir/*`** (`*` 포함 **문자 그대로**)

**해설:**

| 폴더 | `*` | `for` 반복 |
|------|-----|------------|
| **있음** · 안에 `a.txt`, `b.txt` | 펼쳐짐 → 2개 경로 | **2번** |
| **없음** (이 문제) | 펼침 실패 → 패턴 그대로 | **1번** |

→ 에러 없이 **없는 경로 문자열**을 처리할 수 있음 (`1-11`) · 실제 사용 전 **`[ -e "$x" ]`** 로 확인 (PDF slide 13).

**문제:** 한 줄 출력?

**정답:** **`one two three four five `** (끝 공백 가능)

**해설:**

**`echo -n`:** 출력 **끝에 줄바꿈(Enter)을 안 붙임** (`11.md` 1-5 · **n**o newline).

| | 반복마다 출력 |
|--|---------------|
| **`echo "$t "`** (기본) | `one ` ↵ `two ` ↵ … → **여러 줄** |
| **`echo -n "$t "`** (이 문제) | `one ` `two ` `three ` … → **한 줄** |

→ `for`가 5번 돌아도 **줄바꿈 없이** 이어 붙음 · `"$t "` 의 **끝 공백**으로 단어 사이 띄어쓰기.

**목록:** `$list` (따옴표 없음) → 공백으로 **5조각** · `one` `two` `three` `four` `five`.

### 6-6
**상황:**

```bash
for test in "Hello World"
do echo "[$test]"
done
```

**문제:** 출력?

**정답:** **`[Hello World]`** (1번)

**해설:** `for test in "Hello World"` → `test`는 **공백 포함 한 덩어리** (`4-3`).

**`echo`写法 비교** (`test=Hello World` 일 때):

| 코드 | `"` | `[` `]` | 이 문제 출력 |
|------|-----|---------|--------------|
| **`echo $test`** | X | X | `Hello World` |
| **`echo [$test]`** | X | O (글자 그대로) | `[Hello World]` |
| **`echo "$test"`** | O | X | `Hello World` |
| **`echo "[$test]"`** (이 문제) | O | O (글자 그대로) | `[Hello World]` |

**각각 뭐가 다른가:**

- **`echo $test`** — `$test`에 **따옴표 없음** → 쉘이 **공백·탭에서 끊어** `echo`에 넘김. `Hello`·`World` **두 인자**지만 `echo`가 **사이에 공백** 넣어 찍음 → 화면은 `Hello World` (**`"`·`[]` 없음**).
- **`echo [$test]`** — `[` `]` 는 **그냥 글자** · `$test`만 따옴표 없음 → `[Hello World]`.
- **`echo "$test"`** — **한 덩어리**로 출력 · 공백 유지 · `*` 같은 글자도 **그대로** (glob 안 함).
- **`echo "[$test]"`** — `"` 안에서 `$test` 확장 + `[` `]` 도 **그대로** → `[Hello World]`.

**이 문제에선** `[$test]` 와 `"[$test]"` **출력 같음**. 아래처럼 **따옴표 유무가 달라지는** 경우가 있음:

```bash
test="a  b"        # 공백 2개
echo $test         # → a b     (공백 줄어듦)
echo "$test"       # → a  b    (공백 유지)

test="*"
echo $test         # → 현재 폴더 파일 이름들 (glob)
echo "$test"       # → *
```

**해설:** PDF slide 4 — `for` 끝나도 **`city`는 마지막 값 `Daegu` 유지**.

**`do`~`done` 안이 비어 있어도 되나? → X (문법 오류)**


| **`echo …`** | 실제로 뭔가 출력 |

→ 루프는 **도시마다 `city`만 바꿔 가며 돌 뿐** · 본문은 비워 둘 수 없어서 **`:`** 로 채움.

## 부록 — Part1 복습 (핵심만)

**`for` 구조:** `for var in 목록` · `do` … `done` · 한 줄: `for v in list; do`

**목록 만드는 법**

| 방법 | 예 | 반복 |
|------|-----|------|
| 나열 | `1 2 3` | 3번 |
| brace | `{1..10}` `{A..E}` | 10 · 5번 |
| 따옴표 | `"Hello World"` | **1번** (한 덩어리) |
| 공백 분리 | `I do not know` | **4번** |
| 변수+연결 | `list=$list" four"` | 단어 추가 |
| 백틱 | `` `cat f` `` | 명령 결과 |
| glob | `*.txt` `$HOME/*` | 펼친 이름마다 |

**IFS**

| 설정 | 효과 |
|------|------|
| **기본** | 공백·탭·줄바꿈 |
| **`IFS=$'\n'`** | **줄** 단위 |
| **`IFS=:`** | **`/etc/passwd` 필드** |
| **복원** | `IFS.OLD=$IFS` → … → `IFS=$IFS.OLD` |

**C-style:** `for (( i=1; i<=10; i++ ))` — 조건에 **`$` 없음** · `(( ))` 안 산술

**test11~14·Lecture:** `forTest.sh` · `average_with_loops.sh` · `aaa.txt`

**`[ ]` vs `[[ ]]`** (`15.md` 1-13 · PDF 15 slide 12~13)

| | **`[ ]`** | **`[[ ]]`** |
|--|-----------|-------------|
| 정체 | **`test` 명령** | bash **이중 대괄호** |
| 시험 주력 | **파일** `-f` `-d` `-r` … | 차이만 |
| 패턴 | `[ $a = test* ]` → `test*` **글자 그대로** | `[[ $a == test* ]]` → `test`로 **시작**하면 참 |

```bash
name=testing
[[ $name == test* ]]   # 참
[ $name = test* ]      # 거짓
```
