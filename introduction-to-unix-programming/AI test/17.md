## 유형 1. 개념 O/X

---

### 1-1
**문제:** `while [ $i -le 10 ]` 의 **조건(test) 형식**은 `if [ … ]` 와 **같다**. ( O / X )

**정답:** **O**

**해설 — 이 문제가 묻는 것:** while **조건 줄**을 if 와 **똑같이 쓸 수 있냐** → **예(O)**.

**`[ … ]` = test (조건 검사)**

```bash
if [ $i -le 10 ]          # i ≤ 10 이면 참
then
  echo "inside if"
fi

while [ $i -le 10 ]       # ← **같은 모양** · **같은 비교 연산**
do
  echo "inside while"
  i=$((i + 1))
done
```

| | **if** | **while** |
|--|--------|-----------|
| 조건 줄 | `[ $i -le 10 ]` | `[ $i -le 10 ]` (**동일**) |
| 참이면 | `then` **한 번** 실행 | `do`~`done` **반복** |
| 거짓이면 | `then` **스킵** | 루프 **종료** |

→ **달라지는 건 `then` vs `do`~`done`** · **`[ ]` 안 쓰는 법은 같음** (`-le` · 공백 · `$i`).

**PDF slide 2:** while 의 test 는 if-then 과 **exact same format**.

### 1-4
**문제:** `until [ $var -le 50 ]` 은 조건이 **참이 될 때까지** 반복한다. ( O / X )

**정답:** **X**

**해설:** PDF slide 4 — **until** = test 가 **거짓(non-zero)** 인 동안 반복 · **참(0)** 이 되면 **종료** (while 과 **반대**).

| | 조건 **참** | 조건 **거짓** |
|--|-------------|---------------|
| **while** | **반복** | 종료 |
| **until** | **종료** | **반복** |

### 1-5
**문제:** 중첩 루프에서 **안쪽(inner) 루프**는 바깥쪽 **한 번** 돌 때마다 **자기 목록 전체**를 반복한다. ( O / X )

**정답:** **O**

**해설 — 중첩 루프(nested loop)란?** **루프 안에 또 루프**를 넣은 것.

```bash
for a in 1 2              # ← 바깥(outer) · 목록 2개
do
  for b in X Y Z          # ← 안쪽(inner) · 목록 3개
  do
    echo "$a$b"
  done
done
```

**실행 순서 (바깥 1번마다 안쪽 전체):**

| 바깥 `a` | 안쪽 `b` (전부) | 출력 |
|----------|-----------------|------|
| **1** | X → Y → Z | `1X` `1Y` `1Z` |
| **2** | X → Y → Z | `2X` `2Y` `2Z` |

→ `a=1` 일 때 **X Y Z 끝까지** · 그다음 `a=2` 에서 **또 X Y Z 전부** → **2×3 = 6번** (`6-3`).

**1-5가 말하는 것:** 바깥이 **한 칸** 움직일 때마다, 안쪽은 **자기 목록 처음부터 끝까지** 다시 돈다.

---

### 1-6
**문제:** 중첩 `for` 에서 **첫 번째 `done`** 은 **안쪽 루프**를 닫는다. ( O / X )

**정답:** **O**

**해설:** `do` 와 `done` 은 **짝** · **가장 가까운** `do` 와 연결.

```bash
for a in 1 2          # ① 바깥 시작
do                    # ② 바깥 do
  for b in X Y        # ③ 안쪽 시작
  do                  # ④ 안쪽 do
    echo "$a$b"
  done                # ⑤ ← **첫 번째 done** = ④ 안쪽 **끝**
done                  # ⑥ ← **두 번째 done** = ② 바깥 **끝**
```

| `done` | 닫는 루프 |
|--------|-----------|
| **첫 번째** `done` (⑤) | **안쪽** `for b` |
| **두 번째** `done` (⑥) | **바깥** `for a` |

→ `do`/`done` **모양은 같아도** · **안쪽부터** 닫힘 (PDF slide 6).

---

### 1-7
**문제:** 파일 한 줄씩 읽어 필드를 나누려면 **중첩 루프**와 **IFS 변경**을 함께 쓸 수 있다. ( O / X )

**정답:** **O**

**해설:** `users.txt` (`alice:100:A` / `bob:200:B`) 예:

```bash
IFS=$'\n'                        # 바깥: 줄 단위
for line in $(cat users.txt)
do
  IFS=:                          # 안쪽: : 단위
  for field in $line
  do echo "Field: $field"
  done
done
# → Field: alice  Field: 100  Field: A  Field: bob … (6줄)
```

→ **바깥** = 파일 **한 줄씩** · **안쪽** = 그 줄을 **`:` 로 쪼갬** (`4-3`).

---

### 1-8
**문제:** **`break`** 는 **가장 안쪽 반복문만** 빠져나온다(기본). ( O / X )

**정답:** **O**

**해설:**

```bash
for i in 1 2 3
do
  for j in X Y
  do
    if [ $j = Y ]; then break; fi    # 안쪽만 탈출
    echo "$i$j"
  done
done
# → 1X  2X  3X   (각 i마다 Y 전에 break · 바깥 i=1,2,3 계속)
```

→ 기본 **`break`** = **지금 돌고 있는(안쪽) 루프만** 끝냄.

---

### 1-9
**문제:** **`break 2`** 는 **바깥쪽 루프까지** 포함해 반복을 멈출 수 있다. ( O / X )

**정답:** **O**

**해설:**

```bash
for a in 1 2 3
do
  for b in 1 2
  do
    if [ $b -eq 2 ]; then break 2; fi
    echo "$a-$b"
  done
done
# → 1-1 만 출력 · a=1,b=2 에서 **바깥까지** 전부 종료
```

→ **`break 2`** = 루프 **2단계**(안쪽+바깥) **한꺼번에** 탈출 (`4-6`).

---

### 1-10
**문제:** **`continue`** 는 **이번 회차 나머지 명령을 건너뛰고** 다음 반복으로 간다. ( O / X )

**정답:** **O**

**해설:** `forTest.sh` 패턴:

```bash
for i in 1 2 3 4 5
do
  if [ $i -eq 3 ]; then continue; fi
  echo "Iteration $i"
done
# → Iteration 1  Iteration 2  Iteration 4  Iteration 5
```

| `i` | 동작 |
|-----|------|
| 3 | **`continue`** → `Iteration 3` **스킵** → `i=4` 로 |
| 7 + `break` | 반복문 **전체** 종료 (`1-8` 과 다름) |

---

### 1-11
**문제:** **`continue 2`** 는 **바깥 루프의 다음 회차**로 건너뛸 수 있다. ( O / X )

**정답:** **O**

**해설:**

```bash
for a in 1 2
do
  for b in 1 2 3
  do
    if [ $b -eq 2 ]; then continue 2; fi
    echo "$a.$b"
  done
done
# → 1.1  2.1   (b=2 일 때 안쪽 나머지 + 바깥 **다음 a**)
```

→ **`continue 2`** = 안쪽 **이번 회차** 스킵 + **바깥**도 이번 `a` **나머지 안 돌고** 다음 `a` 로 (`6-8`).

---

### 1-12 (루프 출력 · 리다이렉트)
**상황:**

```bash
for a in 1 2 3
do
  echo "line $a"
done > output.txt
```

(`forTest.sh` 는 `done > ccc.txt` 로 같은 방식)

**문제:** 위처럼 **`done` 뒤에 `>`** 를 붙이면, 루프 안 `echo` 출력이 **터미널이 아니라 `output.txt` 파일**에 저장된다. ( O / X )

**정답:** **O**

**해설:**

| | 결과 |
|--|------|
| **터미널** | `line` **안 보임** |
| **`output.txt`** | `line 1` `line 2` `line 3` (3줄) |

**`>` vs `>>` (맞음 · 이 문제는 `>`):**

| 기호 | 동작 |
|------|------|
| **`>`** | **덮어쓰기** — 파일 있으면 **지우고** 새로 씀 |
| **`>>`** | **이어쓰기** — 파일 **끝에** 추가 |

```bash
done > output.txt     # 루프 출력으로 파일 **새로** 만듦 (이 문제)
done >> output.txt    # 기존 내용 **뒤에** 붙임
```

→ `>` / `>>` 는 **`done` 뒤**에 붙여 **루프 전체 stdout** 을 파일로 보냄 (`5-2` · `6-9`).

---

### 1-13
**문제:** `while` 에 **test 두 개**를 쓸 수 있다 — 앞의 `echo $var` 도 조건 판단에 쓰인다. ( O / X )

**정답:** **O**

**해설:** PDF slide 3 — `while` 조건에 **명령을 여러 개** 나열 가능 · **전부 성공**해야 루프 계속.

```bash
var1=2
while echo $var1              # ① 출력 (보통 성공)
      [ $var1 -ge 0 ]         # ② 숫자 비교
do
  echo "inside"
  var1=$((var1 - 1))
done
# 화면: 2 → inside → 1 → inside → 0 → inside → -1 → 종료
```

→ ① `echo` 도 **test 하나** · ②가 거짓이면 **종료** (`6-5` · 마지막 `echo` = **-1**).

---

### 1-14
**문제:** `until` 과 `while` 은 **같은 조건**이면 **항상 같은 횟수** 반복한다. ( O / X )

**정답:** **X**

**해설:** **같은 `[ ]` 라도 반복 시점이 반대** (`6-10`).

```bash
x=3
while [ $x -gt 0 ]; do echo -n "$x "; x=$((x-1)); done
# → 3 2 1 

x=3
until [ $x -gt 0 ]; do echo -n "$x "; x=$((x-1)); done
# → (아무 것도 안 찍힘) · 시작할 때 이미 [ 3 -gt 0 ] 참 → until 은 **바로 종료**
```

| | `[ $x -gt 0 ]` **참** | **거짓** |
|--|----------------------|----------|
| **while** | **반복** | 종료 |
| **until** | **종료** | **반복** |

→ 조건 문자열이 같아도 **횟수 다름**.

## 유형 4. 순서·로직 빈칸

---

### 4-1 (`until` · 마지막 echo)
**상황:** 3-2와 동일 (`var1=100` · 10씩 감소).

**문제:** **마지막으로** `echo "var1: $var1"` 에 찍히는 값?

**정답:** **`60`**

**해설:**

| `echo` 시점 `var1` | 다음 (`-10` 후) | `until [ -le 50 ]` |
|--------------------|-----------------|---------------------|
| 100 | 90 | 거짓 → 계속 |
| … | … | |
| **60** | **50** | 아직 거짓 → 계속 |

|------|--------------|-------------|------------------|

| … | `0` | 참 | `-1` |
| **끝** | **`-1`** | **거짓** → 종료 | |

### 6-7 (`done` 파이프)
**상황:**

```bash

```

**문제:** 출력? (한 줄씩)

**정답:**
```
1
1
3
4
5
```

**해설:**

**`sort -n`:** **숫자 크기** 순으로 정렬 (**n**umeric).

| | 출력 |
|--|------|
| **`done \| sort -n`** (이 문제) | `1` `1` `3` `4` `5` |
| **`sort -n` 없음** | `3` `1` `4` `1` `5` (**for 순서 그대로**) |

**`sort` vs `sort -n` (큰 숫자 있을 때):**

| 입력 | `sort` (문자열) | `sort -n` (숫자) |
|------|-----------------|------------------|
| `2` `10` `1` | `1` `10` `2` (`"10"` 이 `"2"` 앞) | `1` `2` `10` |

→ `done` 뒤에 **파이프 `|`** 로 루프 **전체 출력**을 다음 명령에 넘김 (PDF slide 17~18 · `1-12`는 `>` 파일 저장).

## 부록 — Part2 복습 (핵심만)

**while / until**

| | **while** | **until** |
|--|-----------|-----------|
| 반복 | 조건 **참(0)** | 조건 **거짓(≠0)** |
| 종료 | 조건 **거짓** | 조건 **참** |
| 예 | `[ $i -le 10 ]` (`average_with_loops.sh`) | `[ $var1 -le 50 ]` (`forTest.sh`) |
| 주의 | 루프 안에서 **조건 변수를 바꿔야** 함 | while 과 **반대**로 생각 |

**중첩 루프**

```
for 바깥
do
  for 안쪽
  do
    …
  done    ← 첫 done = 안쪽
done        ← 바깥
```

IFS=$'\n'              # ① 줄 단위
